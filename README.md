# VS Code Insiders changelog

This repo publishes a simple website that lists **what changed in each VS Code Insiders build**.

Generator knobs:
- `MAX_PRS_PER_BUILD` defaults to `100`
- `PR_BATCH_SIZE` defaults to `10`
- `ENABLE_TOP_SUMMARY` defaults to `true`

### Website

https://doview.github.io/vscode-insiders-release-notes/

### Want email updates?

On GitHub, click **Watch → Custom → Releases** to get an email each time a new build is published.
