## Summary

- Agents window: new “Developer: Show Session Details” command shows pinned plain-text info (name, working directories, resource URI) to help identify sessions to clean up.
- Agents window: external Agent Host session visibility now has a one-time banner + “External” submenu, with persisted dismissal and correct restore publication when settings change.
- Agent Host: preserves active peer chats during idle eviction to avoid dropping state during grace periods (plus fixes related session update visibility).
- Agent Host: improved session reliability—stabilized reconnect routing and hardened MCP exact chat routing to reject stale bindings targeting the wrong runtime.
- Integrated Browser Preview: agent-changed local HTML/HTM files now open in the desktop preview UI (trust/BrowserView behavior for untrusted roots unchanged).
- Agent network filters: allow explicitly configured local/private hosts and IPv6 literals (localhost, wildcards, bracketed/bare forms) with fail-closed behavior.
