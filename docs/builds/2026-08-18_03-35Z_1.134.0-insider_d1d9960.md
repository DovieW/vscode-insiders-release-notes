## Summary

- Automations: quick chats now render like full workspace chat rows (metadata, timestamps, identity) for clearer automation history; Sessions sidebar stays compact.
- Add a “recent” external sessions filter (last 7 days/2 sessions) and make “none” the default on 1.134, with updated UI/schema and integration support.
- Fix Anthropic refusal handling so localized refusal messages display correctly, refusals aren’t retried, and refusal state is preserved.
- Fix tunnel discovery on web by registering the tunnel host service before contributions load, restoring the Agents window when tunnels exist.
- Disable the feedback dropdown when the feedback input is empty to prevent opening it via keyboard/mouse, avoiding broken UX.
- Sync “Last Turn Changes” with live streamed edits during a running turn, reducing the delay before streamed output appears in Changes.

## ✨ NEW

- [#331364](https://github.com/microsoft/vscode/pull/331364) **[cherry-pick] Automations: Render quick chats like workspace chats**
  > Makes automations-backed quick chats render like full workspace chat rows (metadata, timestamps, identity), while the Sessions sidebar keeps compact rows. Improves how users read automation history.
- [#331204](https://github.com/microsoft/vscode/pull/331204) **Add recent external sessions filter**
  > Adds a “recent” external sessions filter option (two sessions updated in the last seven days) and makes “none” the default on 1.134. Includes UI/schema updates plus matching integration coverage.

## 🐛 FIXES

- [#331340](https://github.com/microsoft/vscode/pull/331340) **[cherry-pick] Show Anthropic refusals correctly**
  > Handle Anthropic “refusal” as its own completion state, so the UI shows the correct localized refusal message instead of treating it like an empty response. Also prevents retrying refusals and preserves refusal state...
- [#331356](https://github.com/microsoft/vscode/pull/331356) **Disable feedback dropdown for empty input**
  > Disables the feedback split-action dropdown when the feedback input is empty, so users can’t open it via mouse/keyboard/programmatic activation. Adds a regression test for the empty-input state.
- [#331363](https://github.com/microsoft/vscode/pull/331363) **sessions: register a tunnel host service on web (1.134)**
  > Fixes tunnel discovery on the web by registering the required tunnel host service before the contribution loads. This restores the Agents window from showing “Connect a host to get started” when tunnels exist.
- [#331343](https://github.com/microsoft/vscode/pull/331343) **Fix New Session Prompt Description Color**
  > Corrects the New Session prompt option description color hierarchy so it uses the expected foreground styling. This fixes a small UI visual regression.
- [#331276](https://github.com/microsoft/vscode/pull/331276) **[cherry-pick] sessions: Synchronize live last turn changes**
  > Synchronizes “Last Turn Changes” with live streamed edits while a turn is running, then switches to the finalized host changeset when complete. This reduces the visible delay between streamed output and the Changes view.
- [#331209](https://github.com/microsoft/vscode/pull/331209) **agentHost: Filter external Copilot sessions**
  > Filters external Copilot SDK sessions so only recent, repo-backed sessions with the expected clientName are imported on 1.134. Excludes unknown/stale/repository-less sessions to avoid noisy imports.

## 🛠️ DEVELOPER UPDATES

- [#331239](https://github.com/microsoft/vscode/pull/331239) **agentHost: make startup session discovery registry-first**
  > Improves Agent Host startup session discovery performance by prioritizing registry data before heavy per-session I/O, and coalescing repeated list computations. Adds performance-shape tests for the updated behavior.
