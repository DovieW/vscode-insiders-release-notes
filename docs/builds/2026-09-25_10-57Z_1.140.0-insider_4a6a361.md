## Summary

- Agents window Changeset picker: smoother animated stats widget (shared with chat pill), with updated styling for consistent look/feel.
- Classic editor peer chats: rendered as separate tabs with chat-specific URIs, improving multi-peer chat navigation and correctness.
- Chat: persistent progress UI clarified so background work doesn’t look stuck; improves long-running activity messaging and accessibility.
- New: MCP Gallery as an independent Discover customization feed + unified/validated MCP server destination picking for “Add Server” to reduce duplicates and misroutes.
- Fixes major chat/Agents UI and stability issues: nested chat archiving, session switching chat-model retention, subagent/session-tree flicker, and chat progress signal cleanup.
- Fixes reliability/perf regressions: prevent sessions renderer OOM from huge workspaces, plus Agents worktree include matching now follows Git .gitignore semantics.
