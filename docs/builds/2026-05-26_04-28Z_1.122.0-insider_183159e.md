## ✨ NEW

- [#318285](https://github.com/microsoft/vscode/pull/318285) **Add more codenotify for terminal**
  > Expanded terminal CODENOTIFY path coverage so terminal owners get notified for more terminal-related source changes. Helps keep ownership signals accurate as terminal code evolves.
- [#318243](https://github.com/microsoft/vscode/pull/318243) **agentHost: add setting to disable worktreeCreated task auto-dispatch**
  > Adds the setting `chat.agentHost.runWorktreeCreatedTasks` (default false) to stop automatic `worktreeCreated` task dispatch for agent-host sessions. Users can re-enable it when needed.
- [#318240](https://github.com/microsoft/vscode/pull/318240) **agentHost: show fetched URL for web\_fetch**
  > Updates Agent Sessions display for Copilot `web_fetch` so both the start and completion messages include the fetched URL. Adds tests to cover URL-present and URL-missing cases.

## 🐛 FIXES

- [#318267](https://github.com/microsoft/vscode/pull/318267) **Preserve unread state across remote host disconnect**
  > Prevents temporary remote host disconnects from being treated as real session deletions, preserving unread/pin state in the UI. Sessions refresh correctly on reconnect without breaking state.
- [#318273](https://github.com/microsoft/vscode/pull/318273) **chat: fix duplicate command registration for agent-host-copilotcli**
  > Fixes a startup crash caused by registering the same chat command id twice for the agent-host-copilotcli session type. Removes the redundant static registration.
- [#318262](https://github.com/microsoft/vscode/pull/318262) **sessions: restore X-button removal of SSH remote agent host entries**
  > Restores the expected behavior for the SSH remote agent host X button: it now removes the entry from storage before auto-reconnect can run. This stops deleted hosts from coming back on reload.
- [#318257](https://github.com/microsoft/vscode/pull/318257) **Fix agent host SDK terminal tool rendering; disable custom terminal tool by default**
  > Fixes staircase/misaligned terminal output in the agent host SDK tool by normalizing line endings (LF to CRLF) at the adapter boundary. Also disables the custom terminal tool by default for new setups.
- [#318242](https://github.com/microsoft/vscode/pull/318242) **Agent host: clearer worktree git timeout errors and 60s budget**
  > Makes agent-host git worktree failures easier to understand by increasing worktree timeouts from 30s to 60s and summarizing timeout errors into clean one-liners. Full stderr is still logged.
- [#318244](https://github.com/microsoft/vscode/pull/318244) **Fix SSH remote agent host passphrase auth**
  > Fixes SSH agent host passphrase auth by honoring `ssh -G` resolved `IdentityAgent` settings and prompting for passphrases on encrypted private keys. This improves compatibility with common SSH setups.
- [#318229](https://github.com/microsoft/vscode/pull/318229) **fix: handle race condition when logging to removed logger (fixes #318224)**
  > Prevents a race-condition crash in main-process logging by ignoring queued IPC log messages for loggers that were already removed. This avoids the 'Create the logger before logging' error.
- [#318228](https://github.com/microsoft/vscode/pull/318228) **fix: guard against invalid line in provideAltTextQuickFix (fixes #318227)**
  > Guards against out-of-range line numbers in the Copilot Chat alt-text quick fix. If the document changed and the range is stale, it now safely skips offering the quick fix.
- [#317885](https://github.com/microsoft/vscode/pull/317885) **Decode image name for display in carousel**
  > Decodes percent-encoded image filenames for display in the chat image preview carousel (e.g., `Element%20Screenshot` becomes `Element Screenshot`). Falls back to the raw name if decoding is invalid.

## ⬆️ UPGRADES
