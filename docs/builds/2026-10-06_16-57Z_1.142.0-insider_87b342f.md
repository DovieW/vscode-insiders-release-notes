## Summary

- Agent Host: added opt-in Copilot Memory settings (cloud + local); memory is off by default and gated by account preview policy. (#339005)
- Agents Window: PR-to-session is now first-class, creating isolated worktrees and per-PR local branches from pull requests. (#339990)
- Experiments for Agents: chat-scoped layout modes and npm task support routed through Agents capabilities. (#340047, #340049)

- Fixes: restore Copilot shell output previews after reload/restart and improve session canvas/cancellation + various UI alignment bugs. (#339970, #339591, #340075)
