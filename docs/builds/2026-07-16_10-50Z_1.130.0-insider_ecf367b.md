## Summary

- Agents window: add sticky prompt header and revamped prompt timeline UX (single scrollbar lane + fisheye “fan”) with reduced-motion support for easier prompt jumping.
- Codex agent: MCP parity improvements—per-session MCP servers, config updates, OAuth auth flows, plus support for `.agents` skills/hooks and client plugins.
- Agents window: enable markdown editor in the Agents pane and improve chat input CTAs; also move “Open in Agents” action beside the command center for clearer next steps.

- Terminal: allow unix sockets for non-Docker git command chains and improve xterm addon cleanup via a pre-disposal `onWillDispose` hook.
- Quality-of-life fixes in Agents UI: sync docked details pane sizing/sash-collapsing, keep new-session config chips visible during re-resolve, and improve permission picker layout.
