## ✨ NEW

- [#319818](https://github.com/microsoft/vscode/pull/319818) **Don't sneak in bugs :)**
  > Updates .github/CODENOTIFY to notify the right owners about Agents/Sessions layout-related changes. Helps ensure the affected team sees build/UX-impacting updates.
- [#319801](https://github.com/microsoft/vscode/pull/319801) **add requestId**
  > Adds a requestId field to the chat.toolApproval telemetry event so tool approvals can be tied to the specific chat turn. Helps analytics/debugging correlate events.

## 🐛 FIXES

- [#319837](https://github.com/microsoft/vscode/pull/319837) **Disable GitHub specific subagents for extension contributed endpoint providers**
  > Marks the Copilot extension’s contributed chat endpoint as owning authorization, which disables GitHub/CAPI-dependent subagents for those endpoints. Helps prevent the wrong auth/gating behavior.
- [#319813](https://github.com/microsoft/vscode/pull/319813) **Block programmatic webview click and keypress re-dispatch events in some cases**
  > Blocks untrusted webview click/keypress re-dispatch in selected notebook scenarios by checking event trust. Improves security while preserving extension webview keyboard behavior.
- [#319828](https://github.com/microsoft/vscode/pull/319828) **sessions: prevent new-session draft from overriding restored sessions**
  > Fixes a restore race where the “new session” placeholder could asynchronously create an untitled draft and steal focus. Prevents restoring/persisting untitled drafts and hardens the async handler.
- [#319806](https://github.com/microsoft/vscode/pull/319806) **debug: Log errors when loading stored breakpoints/watch expressions (#319805)**
  > Logs errors when loading stored breakpoints and watch expressions fails due to corrupted data, instead of silently swallowing exceptions. Helps diagnose why debug state disappears.
- [#319817](https://github.com/microsoft/vscode/pull/319817) **fix session title widget for new session**
  > Improves the Agents session title widget for new-session state by showing a fallback “New Session” title instead of hiding it. Registers the contribution earlier so it’s available during restore.
- [#319780](https://github.com/microsoft/vscode/pull/319780) **downscale/optimize image attachments**
  > Downscales chat image attachments to reusable thumbnails for the attachment pill and hover preview. Reduces memory/decoding work and improves attachment performance.

## 🔨 REFACTORS

- [#319831](https://github.com/microsoft/vscode/pull/319831) **polish**
  > Polishes the Agents/Sessions window UI by consolidating session header actions into one toolbar and tweaking layout/styling. Benefits usability and keeps the command center centered.
- [#319587](https://github.com/microsoft/vscode/pull/319587) **use \`[Agent Host]\` suffix instead of [Local]**
  > Replaces the UI suffix “[Local]” with “[Agent Host]” for agent host labeling and related comments. Helps users and developers distinguish the surfaces correctly.

## ⬆️ UPGRADES

- [#319799](https://github.com/microsoft/vscode/pull/319799) **feat: enhance Copilot plugin integration with model handling and improved type definitions**
  > Enhances Copilot plugin integration by forwarding optional model info and plugin directory metadata into the SDK session config. Improves plugin typing so session snapshots carry plugin directory details.
