  > When a private extensions marketplace is set by org policy, the Extensions viewlet now shows an info notification with a Settings link to the policy setting. Notification supports dismissing.

## 🐛 FIXES

- [#320879](https://github.com/microsoft/vscode/pull/320879) **Enhance agent and skill discovery: include descriptions in session customization tests and improve skill parsing logic**
  > Skill discovery now pulls each skill’s description from SKILL.md frontmatter and includes it in the parsed results. Session customization tests were strengthened to ensure these descriptions stay intact.
- [#320870](https://github.com/microsoft/vscode/pull/320870) **toolbar ux fix for context and collapse**
  > Improved the Agents chat toolbar layout by moving the context widget back to the secondary toolbar in the sessions window. Also adjusted responsive collapsing so agent-host picker labels don’t break awkwardly.
- [#320855](https://github.com/microsoft/vscode/pull/320855) **Agent debug logs: write to global storage when no workspace is open**
  > Chat debug logging now works even when no workspace is open by falling back to global storage. This restores debug logs, troubleshoot support, and session history for empty-window sessions.
- [#320835](https://github.com/microsoft/vscode/pull/320835) **Filter subagent sessions out of listSessions**
  > Fixed listSessions so subagent child sessions don’t appear as top-level entries. Added unit and integration tests to verify parents remain while subagents stay hidden.
- [#320666](https://github.com/microsoft/vscode/pull/320666) **Update enterprise strings for ULB**
  > Updated enterprise/business chat status quota messages to say Copilot will pause when ULB hard limits are reached. Adjusted unit tests to match the new wording.
- [#320858](https://github.com/microsoft/vscode/pull/320858) **Restrict GPG sandbox permissions for chained commands**
  > Hardened terminal sandbox permissions so GPG-related runtime settings don’t apply to an entire chained command. Added regression tests to confirm chained signed commits stay safe.
- [#320712](https://github.com/microsoft/vscode/pull/320712) **agentHost: fix client tool auto-approval**
  > Fixed client tool auto-approval for agent-host bypass/autopilot mode by preserving tool-call metadata and marking client-owned approvals with the right setting kind. Added tests to cover the new behavior.
- [#320762](https://github.com/microsoft/vscode/pull/320762) **Do not clear agent when switching from initial to commited session**
  > Fixed a regression where switching from a provisional to committed session cleared the selected agent. The agent/mode selection is now preserved across that transition.
- [#320834](https://github.com/microsoft/vscode/pull/320834) **Browser: improve remote proxy stability**
  > Improved stability of the Browser Views remote proxy tunnel by limiting concurrent tunnel connects and cleaning up sockets deterministically on dispose. It also drains keep-alive pools when endpoints change.
- [#314958](https://github.com/microsoft/vscode/pull/314958) **Fix declaration order of File and Reference in CompletionItemKind**
  > Fixed CompletionItemKind enum ordering by swapping File and Reference declarations back into ascending numeric order. This restores consistent sorting/behavior tied to those numbers.
- [#320841](https://github.com/microsoft/vscode/pull/320841) **sessions: keep chat scrollbar at the right edge**
  > Adjusted Agents session view layout so the chat transcript scrollbar stays pinned to the far-right edge. Only the header/tabs remain centered and width-capped, not the chat content.
- [#320839](https://github.com/microsoft/vscode/pull/320839) **fill chat bubble to fit code block**
  > Fixed Agents chat request bubble sizing so bubbles containing code blocks can grow to fit better. This reduces cases where wide code blocks get squeezed by the default max width.
- [#320843](https://github.com/microsoft/vscode/pull/320843) **fix image thumbnail crash on aux windows**
  > Fixed a crash when generating chat image thumbnail elements in auxiliary windows. Thumbnails are now created using the main window’s document instead of the aux window.
- [#320739](https://github.com/microsoft/vscode/pull/320739) **Fix image carousel showing UUID on hover in modal editor title**
  > Fixed modal editor title hover for the image carousel by supplying a proper long title to the resource label. Hover now shows a stable name instead of a changing UUID.
- [#320800](https://github.com/microsoft/vscode/pull/320800) **Support dynamic auto tooltip**
  > Updated the “Auto” model tooltip to build its discount text dynamically and omit it when there’s no discount. This also aligns Copilot CLI tooltip expectations.
- [#320347](https://github.com/microsoft/vscode/pull/320347) **Validate redirect scheme and strip credentials on cross-origin redirects in MCP HTTP client**
  > Hardened MCP HTTP redirect handling by only following http/https redirects and stripping credential headers on cross-origin redirects. This prevents redirects to local schemes and avoids leaking auth.
- [#320754](https://github.com/microsoft/vscode/pull/320754) **Fix raw markdown shown in image carousel caption**
  > Fixed image carousel captions showing raw Markdown by preserving the caption as Markdown/strings during extraction and converting it to plain display text for the carousel UI. Added regression tests.
