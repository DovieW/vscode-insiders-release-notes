## ✨ NEW

- [#316397](https://github.com/microsoft/vscode/pull/316397) **update recommended extensions**
  > Updates the workspace recommended extensions list by dropping EditorConfig and adding the esbuild problem matchers extension. Helps users get better build error parsing out of the box.
- [#316202](https://github.com/microsoft/vscode/pull/316202) **BYOK: Enable Manage Language Models commands without GitHub sign-in**
  > Enables “Manage Language Models” without requiring GitHub sign-in as a first step toward offline BYOK. It still respects enterprise policy so BYOK UI/providers stay hidden when disallowed.

## 🐛 FIXES

- [#315096](https://github.com/microsoft/vscode/pull/315096) **fix: handle network errors in MCP gallery query gracefully (fixes #315094)**
  > Catches network errors in the MCP gallery query so “Failed to fetch” doesn’t become an unhandled error. It logs the issue and returns empty results, keeping the MCP Servers view usable offline.
- [#316422](https://github.com/microsoft/vscode/pull/316422) **fix: handle pending CDP command rejections during debugger detach (fixes #316420)**
  > Prevents unhandled promise rejections during debugger detach by attaching catch handlers to CDP setup commands. This stops teardown from surfacing “target closed while handling command” in error telemetry.
- [#316386](https://github.com/microsoft/vscode/pull/316386) **fix: race activateByEvent with provider registration to prevent auth deadlock**
  > Avoids a remote-tunnel auth deadlock by racing extension activation against auth provider registration. This lets authentication proceed once any host registers the provider instead of waiting on a stuck webworker host.
- [#316359](https://github.com/microsoft/vscode/pull/316359) **Port zsh terminal fixes: zsh pitfalls with shell options and steering text**
  > Ports zsh terminal fixups to the Agent Host so shell options and steering text behave correctly for zsh. Adds tests to cover the session-scoped env behavior and zsh-specific tool guidance.
- [#316264](https://github.com/microsoft/vscode/pull/316264) **fix: revert com server cleanup from update client**
  > Reverts a cleanup change that killed the COM surrogate too early during updater garbage collection. This restores Windows 11 startup reliability for Insiders by keeping the surrogate alive until GC runs.

## ⬆️ UPGRADES

- [#316189](https://github.com/microsoft/vscode/pull/316189) **BYOK: Custom Endpoint provider — Chat Completions, Responses, and Messages API support**
  > Upgrades BYOK “Custom Endpoint” to support OpenAI Responses and Anthropic Messages, and deprecates the older customoai provider for Insiders. Requests and auth headers are routed to the right API shape.
