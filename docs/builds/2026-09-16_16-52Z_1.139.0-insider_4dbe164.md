## Summary

- Suggest TypeScript 7 when no language server plugins are installed—prompts an install/experiment so TypeScript language features stay available without manual setup.
- Dev Containers now work for SSH/Tunnel sources in Sessions/Agents Window, enabling the same “Use Dev Container” workflow on remote connections.
- JSON extension now auto-matches OpenAPI/OpenAPI-related filenames to the right SchemaStore schemas, improving schema association without extra config.
- Fix repeated Agent Host sign-in for stale sessions, reducing annoying auth loops by recovering with alternative same-account tokens when possible.
- Chat now surfaces out-of-band subagent approvals even when the original response is offscreen/virtualized, so Allow/Skip actions work reliably.
- Codex recovery no longer gets stuck on large paginated threads (HTTP 413) by fixing the revert/history handling during fork creation.

- [#335369](https://github.com/microsoft/vscode/pull/335369) **Suggest TypeScript 7 for users with no plugins enabled**
  > Starts an install prompt/experiment for the TypeScript 7 extension for users who have no language server plugins registered. This helps keep TypeScript language features available without extra setup.
- [#336249](https://github.com/microsoft/vscode/pull/336249) **sessions: Support Dev Containers on SSH and Tunnel hosts**

  > Extends the JSON extension’s default schema matching to include OpenAPI/OpenAPI-related filenames. This auto-associates OpenAPI documents with the right SchemaStore schemas.

## 🐛 FIXES

- [#336344](https://github.com/microsoft/vscode/pull/336344) **agentHost: Avoid repeated sign-in for stale sessions**
