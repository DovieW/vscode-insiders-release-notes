## Summary

- Chat: show ChatGPT as the source on model chips/annotations (“(ChatGPT)”) and labels, so users can tell which models came from ChatGPT at a glance.
- Chat: enable the “permissions sandbox” toggle by default, making the sandbox option visible without manually opting into the experiment.
