## Summary

- Add a chat customization migration page (“Migrate Configured Locations”) with an experimental enablement to move agents/instructions/skills into supported locations.
- Agents: open Dev Container workspaces in Agents (matches the local folder and preselects Dev Container execution) and enable switching branches for folder-based Agent sessions.
- Chat: queue messages for busy target chats in the send_message tool (FIFO), plus fix chat picker focus/keyboard navigation.
- Sessions/Agents: convert workspace-less sessions to workspace sessions and add a “No workspace” option in the new session picker.
- Policy: make extensions.gallery.authProvider controllable by enterprise policy (in sync with extensions.gallery.serviceUrl), and keep terminal sandbox toggle editable when bypass is allowed.
- Browser/Chat fixes: support opening .mhtml/.mht in the integrated browser and stop chat UI/layout jumps (reserve space for chat pets).
