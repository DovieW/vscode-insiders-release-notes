## Summary

- Sessions chat tabs now match modern editor tabs (hover/focus close, correct multi-session + accessible states), making chat navigation and tab behavior more consistent.
- PatchBased02 can now use optional `memory.rejectedEdits` to remember previously rejected diff suggestions, helping avoid repeated proposals during apply/patch flows.
- Fixes Agents sessions UX: removed obsolete “Local” provider from Agents window and improved aux-only tab restoration so only “Changes” and “Files” stay visible.
- Preserves terminal panel height when returning from Quick Chat back to the editor, preventing layout jumps; includes regression coverage for the workspace → Quick Chat → workspace flow.
- AGENT/telemetry: corrects Agent Host edit attribution in focus windows and prevents duplicate Copilot Chat GitHub MCP sync in Copilot CLI Agent Hosts.

- [#327367](https://github.com/microsoft/vscode/pull/327367) **Add optional rejected edit memory to diffpatch prompt**
  > Adds an opt-in `memory.rejectedEdits` prompt option for PatchBased02, storing a small annotated history of rejected edits. Helps the model avoid repeating suggestions the user already rejected.

  > Updates Sessions chat tabs to match modern editor tab layout and styling, including hover/focus close actions and correct multi-session/accessible states.

## 🐛 FIXES

- [#329623](https://github.com/microsoft/vscode/pull/329623) **agentHost: exclude Copilot Chat GitHub MCP sync**
  > Prevents Copilot Chat’s GitHub MCP provider from being synced into Copilot CLI Agent Hosts, avoiding duplicate GitHub sync behavior. Keeps user-configured GitHub servers and existing MCP support working correctly.
- [#329603](https://github.com/microsoft/vscode/pull/329603) **sessions: remove Local harness from Agents window**
  > Removes the obsolete “Local” sessions provider from the Agents window so it no longer shows or advertises a misleading Local option. Adds regression tests for the Agents window provider list/labels.
- [#329472](https://github.com/microsoft/vscode/pull/329472) **agentHost: Attribute edits in focus windows**
  > Corrects telemetry attribution for Agent Host edits in focus windows by reclassifying retained edit ranges to the Agent Host source. This preserves the existing counts while restoring the proper “agentHost” identity.
- [#329325](https://github.com/microsoft/vscode/pull/329325) **Fix stale session changes document lifecycle**
  > Fixes stale Agents “Changes” editor cleanup so archived sessions don’t keep resolved text models alive. Also guards tsserver event delivery to avoid recreating watchers after disposal.
- [#329608](https://github.com/microsoft/vscode/pull/329608) **sessions: preserve panel height when restoring editor**
  > Preserves the bottom terminal panel height when returning from Quick Chat and restoring the single-pane Editor. Adds a regression test covering the workspace → Quick Chat → workspace navigation flow.
- [#329601](https://github.com/microsoft/vscode/pull/329601) **Dont show reopen as preview/text in agents window, as editor type dropdown offers this**
  > Hides redundant Markdown “Reopen as Preview/Source” editor-title actions inside the Agents window. The actions remain available in other windows.
- [#329579](https://github.com/microsoft/vscode/pull/329579) **Style overrides: Improve layout and visibility of activity and composite bars**
  > Improves styling for the activity bar and modern UI tabs, including spacing and focus/hover indicators (better accessibility). Adjusts CSS to keep layout consistent across sizes and themes.
- [#329590](https://github.com/microsoft/vscode/pull/329590) **sessions: keep aux-only tabs limited to Changes and Files**
  > Fixes session navigation where Details-only layouts could asynchronously restore extra Aux-only tabs after editor collapse. Now keeps only managed “Changes” and “Files” tabs and adds regression coverage.
- [#329534](https://github.com/microsoft/vscode/pull/329534) **scm: Avoid quick diff after model disposal**
  > Prevents SCM quick-diff from running if the underlying text model was already disposed. Stops queued quick-diff work from touching a dead model (fixes crash/exception risk).
- [#329581](https://github.com/microsoft/vscode/pull/329581) **Fix can't hit enter really fast on simple file picker**
  > Fixes a simple file picker issue where very fast Enter presses could pick the wrong thing or lag. Adds synchronous matching for direct-child folders and regression tests.
- [#329580](https://github.com/microsoft/vscode/pull/329580) **sessions: improve Changes view layout**
  > Improves the Sessions “Changes” view layout by better prioritizing changed files and managing split-view sizing. Also fixes per-session collapse-state behavior and adds lifecycle/fixture tests.
- [#329573](https://github.com/microsoft/vscode/pull/329573) **Version Markdown code block editor API**
  > Adds API versioning for dynamic Markdown code block editor contributions and rejects invalid/unsupported versions, so only compatible providers are advertised to the Markdown editor.
