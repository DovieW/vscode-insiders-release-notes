## 🐛 FIXES

- [#319493](https://github.com/microsoft/vscode/pull/319493) **[cherry-pick] Revert "[Linux-Sandboxing]: Ubuntu 24.04 silently fails due to App Armor profile on bwrap (#319061)"**
  > Reverts the Ubuntu 24.04 AppArmor remediation for sandboxed terminals, while keeping the later network-allow retry. Helps Linux/WSL users where sandbox commands silently failed.
- [#319494](https://github.com/microsoft/vscode/pull/319494) **[cherry-pick] [cherry-pick] terminal: fix Linux sandbox wrapper env assignment**
  > Fixes a Linux sandbox wrapper environment assignment for terminal commands. Prevents incorrect env values when running sandboxed terminals.
- [#319483](https://github.com/microsoft/vscode/pull/319483) **[cherry-pick] Short-circuit getAllChatEndpoints lookup for execution subagent**
  > Avoids calling getAllChatEndpoints when the execution subagent can’t actually be enabled. Reduces unnecessary endpoint lookups and keeps behavior unchanged when the gate allows it.
- [#319407](https://github.com/microsoft/vscode/pull/319407) **[cherry-pick] build: clamp PT\_LOAD p\_align to 4 KiB on linux-x64 node binary**
  > Build fix for the bundled Linux x64 Node binary: clamps PT_LOAD p_align to 4 KiB to satisfy WSL1 binfmt_elf. Prevents Node startup failures under WSL1 (no runtime behavior change).
- [#319408](https://github.com/microsoft/vscode/pull/319408) **[cherry-pick] Fix BYOK models startup race**
  > Fixes a BYOK startup race that could temporarily save the wrong last-known state and flicker BYOK-gated UI. Ensures state is only persisted after extension scan and first config load.
- [#319476](https://github.com/microsoft/vscode/pull/319476) **[cherry-pick] Gate subagents for BYOK endpoints and require gemini-3-flash for execution subagent**
  > Tightens agent subagent gating for BYOK endpoints and the execution subagent. BYOK endpoints disable relevant subagents, and execution requires gemini-3-flash to be available.
- [#319450](https://github.com/microsoft/vscode/pull/319450) **Disable CLI sandbox**
  > Introduces an experiment-controlled kill switch to disable the CLI sandbox for Copilot CLI sessions. Helps avoid a Linux “broken native module” error when sandboxing triggers failures.
- [#319268](https://github.com/microsoft/vscode/pull/319268) **Ignore unsupported host lists on macOS**
  > Forwards configured allowed/denied network host lists into the CLI sandbox policy, but ignores them on macOS where they can’t be enforced. Prevents accidental allow-all outbound behavior.
