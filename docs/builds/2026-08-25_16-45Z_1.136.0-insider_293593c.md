## Summary

- Agents chat: add theme-aware background layout management actions (Command Palette/context menu) plus “Clear Background Image”, with reactive visibility and accessibility help text (#332569).
- Chat: summarize the Agent Merge machine prompt in a collapsible “Agent Merge” widget so transcripts don’t show a raw wall of prompt text (#332496).
