## ✨ NEW

- [#313256](https://github.com/microsoft/vscode/pull/313256) **Support prompting the user to share an existing browser tab**
  > Improves the integrated browser “open” chat flow to prompt you to reuse an existing browser tab when possible, instead of always opening a new page. Also refactors carousel dismissal handling into a shared helper.
- [#313260](https://github.com/microsoft/vscode/pull/313260) **add ChatSessionCustomizationType.userInvocable**
  > Adds a new `userInvocable` flag to chat session customization items and carries it through ext host ↔ main thread plumbing. This lets providers indicate which customizations users can invoke.
- [#313127](https://github.com/microsoft/vscode/pull/313127) **telemetry: add workspaceChunkSearch.tryInit event for cold-init tracking**
  > Adds a new telemetry event, `workspaceChunkSearch.tryInit`, to track cold-init duration and outcomes for the workspace chunk search service. Helps diagnose init latency and failure modes in the field.
- [#312868](https://github.com/microsoft/vscode/pull/312868) **sessions: add customizations overview header action**
  > Adds a home icon action to the Agents sidebar “Customizations” header to jump back to the management editor welcome/overview page. Includes browser tests for expanded and collapsed states.

## 🐛 FIXES

- [#313264](https://github.com/microsoft/vscode/pull/313264) **chore: remove cleanup step**
  > Removes an extra cleanup step from the Linux product build pipeline (including disk-space and Playwright cache cleanup). Benefits build stability/simplicity by reducing unnecessary tail actions.
- [#313117](https://github.com/microsoft/vscode/pull/313117) **Fix issue with hover reappearing on Esc, Alt-tab, link click etc.**
  > Prevents managed hovers from briefly reappearing after dismissing them (Esc, Alt-Tab, link click, etc.). Adds regression tests so dismissed hovers stay dismissed.
- [#313249](https://github.com/microsoft/vscode/pull/313249) **Fix RunInTerminalTool hang when shell exits before/during execute()**
  > Fixes a hang in the run-in-terminal chat tool when the terminal shell exits before `execute()` finishes wiring up listeners. Adds early-out handling plus unit tests for “already exited” and “already closed” cases.
- [#313254](https://github.com/microsoft/vscode/pull/313254) **Terminal: prevent paste auto-exec when clipboard has trailing newline**
  > Stops auto-execution when pasting clipboard text with a trailing newline into the integrated terminal, unless bracketed paste is active. Users now paste to the prompt and can press Enter to run.
- [#313252](https://github.com/microsoft/vscode/pull/313252) **Resolve parent directory when realpath fails with ENOENT in edit confirmation**
  > Improves edit-confirmation safety checks when `realpath` fails with ENOENT for create-file scenarios. It now resolves the parent directory so symlink-related safety checks still apply.
- [#313244](https://github.com/microsoft/vscode/pull/313244) **Detect chevron-style interactive prompts and fix indefinite foreground hang on unrecognised prompts**
  > Fixes an indefinite foreground hang when terminal prompts from libraries (like `prompts`/`inquirer`) aren’t recognized. Adds chevron-style detection and ensures an input-needed event fires on the extended timeout.
- [#313080](https://github.com/microsoft/vscode/pull/313080) **trackIdleOnPrompt logging**
  > Improves terminal shell-integration debugging and robustness for bash under `run_in_terminal`. Adds detailed idle-on-prompt trace logs and hardens bash DEBUG-trap handlers against `set -e`.
- [#313200](https://github.com/microsoft/vscode/pull/313200) **Fix deleting sub-session when it is not active**
  > Fixes a multi-chat session cache update bug where deleting a child session could be treated as removing the whole standalone session. Now resolves group IDs before cache mutation so the parent emits the correct change...
