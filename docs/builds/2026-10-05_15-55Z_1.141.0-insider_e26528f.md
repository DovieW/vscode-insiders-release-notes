## Summary

- Fix extension auto-updates to keep checks on their normal polling cadence (instead of rescheduling), and clarify delayed-update eligibility messaging.
- Fix unread/read state handling for legacy Agent Hosts by syncing read changes at the session level based on protocol support.
- Fix Agent Host session unread/read state by syncing from participating chat read-state changes and only marking read when the last unread chat is read.
- Fix Agents UI so PR pills only display PR artifacts created by the owning chat (not other chats sharing a folder).
- Avoid downloading the Codex SDK for unused draft chats; SDK now loads only when a draft materializes.
- Refine Agents Window “Created In” defaults and accessibility labels, including better formatting for unknown application names.
