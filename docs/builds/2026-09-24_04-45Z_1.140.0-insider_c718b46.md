## Summary

- chat: Add a unified customization marketplace in the Discover UI, combining multiple public feed sources (default GitHub) so users can browse, search, and install skills/agents/plugins in one place.
- Agents/Sessions: Let chats work in their own folder and show the active chat folder in UI; also add contextual composer guidance for new sessions and parallel work.
- terminal: Open retained terminal output from chat/terminal previews, preserving full spilled output with correct selection/scroll/link behavior.
- Fixes for chat/Agents reliability: preserve sessions across window moves, paginate restoration for very large sessions, and fix idle/blank UI issues like sticky headers.
- Security/robustness: Harden SSH host key verification and Agent Host by rejecting client-dispatched server-only actions; also normalize imported URI/chat rendering to prevent malformed-link issues.
