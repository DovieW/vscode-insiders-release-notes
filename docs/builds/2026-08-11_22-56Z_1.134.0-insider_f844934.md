## Summary

- chat: save dirty editors before sending messages with new default-on `chat.saveBeforeSend` setting (excluding untitled editors) to prevent accidental missing changes.
- Omni chat: add command-intent routing with a “Run command” review flow for eligible built-in commands, preserving focus and keeping other commands in chat.
- Automations: add “Needs Input” indicator for runs waiting on user input, plus a Stop action for running automation history rows (accessible + keyboard).
- Sessions/Agents: improve signed-out experience—offer “Sign in to GitHub” from the GitHub workspace picker and support signed-out Copilot Agent Host sessions for advertised BYOK models.
- chat/Omni UX fixes: allow Omni input to grow for multiline pastes, align Omni chat width with command palette, and fix send icon styling.
