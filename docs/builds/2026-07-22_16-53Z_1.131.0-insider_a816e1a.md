## Summary

- Add `list_browser_pages` tool to `vscode.lm.tools`, letting listing agents fetch session-aware integrated browser pages.
- Agents: New session Quick Pick (“New Session in Folder…”, Cmd/Ctrl+O) to choose the folder, with recents kept in sync with the existing dropdown.
- Chat: config-only slash commands now apply session configuration before submitting, so typed config updates take effect immediately.
- Fix chat UI issues: streaming row height no longer gets clipped/stale until resize, and the scroll-down button behavior is corrected.
- Fix Agent Host/agents reliability: restore last-used chat models instead of `Auto`, and preserve correct terminal output order for fast commands.
