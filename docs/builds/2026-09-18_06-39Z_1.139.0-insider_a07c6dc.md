## Summary

- chat: add opt-in persistent working progress (experimental) with selectable animation styles so in-progress status stays visible across chat updates.
- mcp: support remote URL variables for server installation templates—VS Code now resolves transport-declared variables, prompts for inputs, and rejects conflicting definitions.
- sessions: add `sessions.showChatTabs` to control single vs multiple chat tab presentation, keeping headers and tab state in sync.
- Explorer: improve paste error messaging to show the real underlying file operation failure, plus fix rename/create failing in unfocused windows.
- Fix Copilot and dictation reliability/performance: restore BYOK context behavior, speed up large-search content exclusion filtering, and fix dictation restart + failure outcome reporting.
