  > Adds trace timing logs around the chat session opening pipeline. Helps diagnose slow session startup by correlating timings across workbench and main-thread layers.
- [#313855](https://github.com/microsoft/vscode/pull/313855) **feat(otel): make attribute truncation configurable**
  > Adds a setting to control how much OTel attribute content is truncated, with `0` meaning unlimited (default). Users can tune it for backend limits via setting or env var.
- [#313841](https://github.com/microsoft/vscode/pull/313841) **agent host: eagerly create sessions when a folder is picked**
  > Creates agent-host sessions earlier during folder pick using “provisional sessions,” materializing real resources only on first message. Speeds up UI interaction and avoids a duplicate createSession on first send.
- [#313575](https://github.com/microsoft/vscode/pull/313575) **AHP/Customizations: BrowserPluginGitCommandService for adding plugins in web**
  > Implements browser/web support for installing agent plugins from GitHub by fetching refs, listing trees, downloading blobs, extracting, and caching SHAs. Adds tests and auth handling so it works without local git.
- [#313741](https://github.com/microsoft/vscode/pull/313741) **Add support for UBB in manage models view**
  > Adds token/input/output/cache cost fields to the Chat “Manage Models” UI and model metadata contract (UBB support). The widget now shows usage-based pricing in the table and hover.
