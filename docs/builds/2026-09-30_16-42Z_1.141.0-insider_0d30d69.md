## Summary

- Add “Download…” for remote files from the Agents/editor title header, letting you save remote content locally with correct context and error handling.
- Agents titlebar action experiments: add copy/hover behaviors (e.g., customizable initial label + optional hover expansion) with experiment-based UI interaction changes.
- JSON schemas: allow `${workspaceFolder}` in `fileMatch` patterns to anchor matches to the workspace path and avoid overly-broad implicit `**/` matching.
- Fix: touch interaction no longer mistakenly selects/auto-closes the workspace picker after opening it.
- Fix remote Agent Host connection timeouts by treating incoming bytes as activity to prevent reconnect loops on large SSH/tunnel transfers.
- Agent Host: retract orphaned provisional sessions during startup reconciliation and notify clients to avoid stale session catalog entries.
