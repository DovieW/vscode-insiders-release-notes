## Summary

- Add “Adhoc Request Sender” mode in the simulation workbench, with a dedicated UI and highlighted prompt tags for faster ad-hoc testing.
- Agents window: session header now always shows a labeled “+ New Chat”, and sessions picker supports quick navigation via keybinding hold/cycle.
- Fix chat streaming stop so cancellation propagates to `provideLanguageModelChatResponse` across processes.
- Agents window session header diff-stats and pill now open the correct default changeset, keeping totals consistent with the Changes view.
- Sessions: GitHub PR polling no longer uses stale renderer HTTP cache, so PR icons/status update reliably.
- AgentHost: expand changeset commit/sync and add PR creation operations with configurable auto-merge options.
