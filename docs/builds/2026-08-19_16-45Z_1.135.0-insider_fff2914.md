## Summary

- Chat: back Terminal Chat with an experimental Agent Host backend (local fallback). Adds ephemeral session lifecycle and terminal-specific per-turn instructions for a more responsive experience.
- Agents session list: move section chevrons to the left and show them only on hover/keyboard focus, with refined icons and spacing for better discoverability.
- File Explorer: preserve user-defined workspace title casing (no forced capitalization), fixing named vs untitled title handling.
- Fix a chat sessions race that could run before the grid’s first layout, leaving the chat UI partially broken—now guarded and covered by a regression test.
- Hide “Create Session from Pull Request” in Agents when the workspace lacks a GitHub remote, preventing a dead/unavailable action.
