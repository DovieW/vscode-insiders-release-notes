## 🐛 FIXES

- [#320658](https://github.com/microsoft/vscode/pull/320658) **Remove copilot is paused label for inline completions**
  > Adjusted the chat status dashboard so the global “Copilot is paused” callout shows only when chat quota is exhausted, not when only inline suggestion/completions are paused. Added tests to prevent future confusion.
- [#320753](https://github.com/microsoft/vscode/pull/320753) **Fixes builtin markdown editor paths**
  > Fixed built-in Markdown editor asset paths by moving the webview bundle output to a consistent folder and updating the provider and build/ignore config accordingly.
- [#320775](https://github.com/microsoft/vscode/pull/320775) **copilot: don't show quota dialog for automatic rename suggestions**
  > Prevented the Copilot “Quota Exceeded” modal from interrupting automatic AI rename suggestions during symbol rename (F2). The modal now only appears for explicit user-invoked suggestions.
- [#320769](https://github.com/microsoft/vscode/pull/320769) **fix padding of input part in sessions window**
  > Fixed a sessions window layout issue where the chat input could render too wide. The input sizing math now accounts for the extra left/right padding in the sessions window.
- [#320782](https://github.com/microsoft/vscode/pull/320782) **Fix empty terminal command for terminal tools without input**
  > Fixed a regression where some terminal-kind tool calls briefly showed an empty terminal command. Now the UI only treats a tool as terminal once its command text exists, and tests were added.
- [#320624](https://github.com/microsoft/vscode/pull/320624) **Preserve image source provenance across chat reference API boundary**
  > Restored image source provenance (pasted vs URL) when converting chat prompt references by carrying `isPasted`/`isURL` metadata through the API boundary. This improves image-source telemetry accuracy.
- [#320743](https://github.com/microsoft/vscode/pull/320743) **fix setting active session when new session is submitted**
  > Fixed Sessions grid “active session” staying out of sync after providers replace a draft with a committed session. Added a `replaceActiveSession` path and expanded tests for replacement scenarios.
- [#245751](https://github.com/microsoft/vscode/pull/245751) **Fixed typo in cli update**
  > Corrected a typo in the CLI self-update message (“to to date” → “up to date”), improving the user-facing output when no update is needed.
- [#320707](https://github.com/microsoft/vscode/pull/320707) **agentHost: describe empty attachment tool results**
  > Improved handling for tool calls that succeed but have no text, by describing the attached resource type (image/file/both) instead of returning a generic empty placeholder. Updated tests accordingly.
