## Summary

- Chat: pasted GitHub issue/PR URLs now render as compact owner/repo#number references (with icon) via new setting `chat.pasteGitHubLinksAsReferences` (default on).
- Multi-diff editors now show binary file changes instead of hiding them, with an accessible “Binary file changed” placeholder and “Open Diff” action.
- Agents: multi-diff/browsing UX updates—multi-diff binary visibility, changeset picker labels use text ellipsis, and more Actions moved to the right menu.
- Agents/Agent Host: Agent Merge improvements—added draft PR “Create Draft PR &amp; Agent Merge”, better merge status presentation, and reliably shows “Agent Merge Changes” after restore.
- Fixes for chat/navigation and session UI: Chat mouse Back behavior restored; session-row hover/layout fixed in narrow panes; session progress now reflects active child chats.
