## ✨ NEW

  > Renames the “Ensemble” concept to “Fusion” across the codebase, updating user-facing strings and configuration metadata (while keeping existing rollout setting IDs).
- [#341666](https://github.com/microsoft/vscode/pull/341666) **sessions: add a Run in the cloud switch to the automation dialog**
  > Adds a “Run in the cloud” switch to the New automation dialog and updates the cloud workspace picker so testers can choose Cloud more clearly.
- [#341239](https://github.com/microsoft/vscode/pull/341239) **chat: add Sunburst setting and image usage costs**
  > Adds a new chat setting to enable native GPT Image 2.5 Sunburst generation and shows token/AI-credit cost rates in Settings and tool info.
- [#341698](https://github.com/microsoft/vscode/pull/341698) **Agent Host: pre-warm Copilot sessions before the first send (experimental)**
  > Adds an experimental “prewarm sessions” option that starts Copilot draft sessions and MCP servers before the first send to reduce perceived startup time.
- [#341908](https://github.com/microsoft/vscode/pull/341908) **agentHost: interoperate on session pull request metadata**
  > Adds interoperability between VS Code and Copilot hosts for the current session’s pull request metadata via `copilot.githubReferences`, including discovery, live updates, and offline restoration.
- [#341911](https://github.com/microsoft/vscode/pull/341911) **Enable native image generation for cloud sandbox sessions**
  > Enables native image generation for new cloud sandbox sessions when the connected host supports it and confirms the setting, across both Editor and Agents windows.
