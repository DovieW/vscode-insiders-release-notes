## Summary

- Agents: added `sessions.useWorktree` setting to control whether Agents uses a worktree for the first session, letting you tune how session workspaces are set up.
- Fix: Codex workspace “hooks” trust is now stored per agent thread (instead of global/bypassed), with safe fallback and warnings when hook lookup fails.
- Chat: moved the “pet” spacer outside response content to keep chat responses more compact and remove the extra empty element.
- Authentication: express token/session expiry now uses relative milliseconds (`expiresAfter`) while keeping the protocol’s seconds field compatible.
- Agents: fixed Agent Host sandbox synchronization and permission picker updates by resolving the sandbox OS correctly and refreshing UI when settings change.
