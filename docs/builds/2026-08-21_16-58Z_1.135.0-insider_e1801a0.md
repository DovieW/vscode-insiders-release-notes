## Summary

- Chat: add paste threshold adjustment + “Insert in Prompt” for pasted pills; Ctrl/Cmd+Shift+V now pastes plain text into chat.
- TypeScript: opt-in “TypeScript 7 language context” with new settings, providers, and inline suggestion support (keeps TS6 behavior via routing).
- Agents/Chat: verify workspace trust for all session folders before starting an agent host session to prevent running in untrusted local folders.
- Fix session pill controls and UI: allow toggling chat pills with no data and improve compact chevron alignment in sessions dropdown.
- Agents: prevent PR-created sessions from cross-repo PRs; ensure worktrees checkout the PR branch correctly.
- Fix tab reporting: stale isActive no longer causes background tabs to be incorrectly reported as activeTab.

## ✨ NEW

- [#331978](https://github.com/microsoft/vscode/pull/331978) **Implement paste threshold adjustment and "Insert in Prompt" feature**
  > Adds a chat setting to control when pasted content becomes an attachment, and lets users right-click a pasted pill to insert the text back into the prompt. Also binds Ctrl/Cmd+Shift+V to paste plain text in chat.
- [#331798](https://github.com/microsoft/vscode/pull/331798) **Add TypeScript 7 context support**
  > Adds an opt-in “TypeScript 7 language context” feature, including context providers and inline suggestion support via new settings. Includes routing to keep TypeScript 6 behavior working.

## 🐛 FIXES

- [#331977](https://github.com/microsoft/vscode/pull/331977) **Allow toggling chat pills that have no data**
  > Makes session chat pill visibility toggles work even when the session reports no data for that pill kind. Only the overall toolbar row remains hidden when nothing has data, same as before.
- [#331893](https://github.com/microsoft/vscode/pull/331893) **sessions: Centre the chat pill chevron on the compact glyph**
  > Improves alignment of the chat pill dropdown chevron in the sessions UI by switching to the compact chevron glyph and simplifying the related CSS selectors. Also reuses shared tooltip/ARIA metadata for consistency.
- [#331895](https://github.com/microsoft/vscode/pull/331895) **chat: verify workspace trust for a session's folders before sending**
  > Before starting an agent host session, verifies workspace trust for all local folders the session will use. This prevents running/spawning in untrusted local folders (covered by trust gating tests).
- [#331962](https://github.com/microsoft/vscode/pull/331962) **Agents - limit creating a session from a pull request in the same repository, but ensure that the worktree is set up correctly**
  > Restricts agent sessions created from pull requests to same-repo PRs and configures worktrees to check out the PR branch directly. Ensures the worktree setup is correct and covered by new/updated tests.
- [#331928](https://github.com/microsoft/vscode/pull/331928) **sessions: Remove session metadata setting**
  > Removes the chat setting that controlled where session metadata shows, and standardizes the UI so metadata pills appear in one place above the chat input. Updates accessibility wording and related UI tests/fixtures.
- [#331927](https://github.com/microsoft/vscode/pull/331927) **Agents - add isExternal and pull request fields to session telemetry**

- [#331924](https://github.com/microsoft/vscode/pull/331924) **Agents - new session action should appear leftmost**
  > Reorders Agents window section toolbar actions so “New Session” is shown leftmost (with archive/done actions moved to the second position).
- [#331913](https://github.com/microsoft/vscode/pull/331913) **Make metered connection status bar item more visible**
  > Makes the metered connection status bar item more visible by applying built-in warning styling while keeping it theme-aware (including high-contrast behavior).

## 🛠️ DEVELOPER UPDATES

- [#331952](https://github.com/microsoft/vscode/pull/331952) **Fix stale isActive causing background tabs to be reported as activeTab**
  > Fixes a bug where background tabs could be incorrectly reported as the active tab due to stale cached `isActive` state. Adds a regression test covering label/dirty/pin/preview update cases.
- [#331970](https://github.com/microsoft/vscode/pull/331970) **Render the session changes pill from a cache**
  > Caches recent session change counts so the session changes pill appears immediately when opening a session, even before provider data arrives. Clears the cache when a session reports no changes to avoid stale pills.
- [#331961](https://github.com/microsoft/vscode/pull/331961) **Clarify commit artifact guidance**
  > Updates internal agent artifact guidance so discovered commits are shown by default, while agent-created commits are only recorded when the user explicitly asks. No direct end-user feature change expected.
- [#331946](https://github.com/microsoft/vscode/pull/331946) **Group session artifact images in carousel**
  > Groups session artifact images into a dedicated Images section and opens them in the preview carousel starting at the selected image. Includes unit tests for grouping and carousel start index.
- [#331841](https://github.com/microsoft/vscode/pull/331841) **Remove unnecessary Copilot token usage in Agent Host**
  > Removes extra Copilot token minting from Agent Host and relies on existing GitHub OAuth/user-discovery data instead. Adds regression tests to keep org alias mapping working correctly.
