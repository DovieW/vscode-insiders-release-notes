## 🐛 FIXES

- [#321104](https://github.com/microsoft/vscode/pull/321104) **Agents - add missing trusted-types**
  > Updates the Agents window pages to allow the `lit-html` Trusted Types entry under the existing CSP rules. This prevents blocked UI code and aligns Agents with Sessions behavior.
- [#321097](https://github.com/microsoft/vscode/pull/321097) **build: stamp product info for tgrep executable**
  > Fixes a Windows build packaging issue by stamping product info on the tgrep executable. Helps CI pass when `VersionInfo.ProductName` was missing.
- [#321089](https://github.com/microsoft/vscode/pull/321089) **Fix and use supportsAutoModel session-type flag for the model picker**
  > Improves model picker session behavior by using a new `autoModelUnavailable` flag instead of guessing from model requirements. This fixes incorrect “Auto” fallback and empty-model states.
- [#321044](https://github.com/microsoft/vscode/pull/321044) **update manifest in remote channels whenever manifest changes**
  > Updates the extension gallery manifest service so remote channels refresh whenever the manifest changes. Helps keep the gallery consistent after updates instead of only loading once.
- [#321011](https://github.com/microsoft/vscode/pull/321011) **Fix model configurations syncing across editors and locations**
  > Fixes model configuration syncing so settings don’t leak across already-open editors/locations. Each editor now keeps its own model configuration when sending chat.

## ⬆️ UPGRADES

- [#320966](https://github.com/microsoft/vscode/pull/320966) **nes: update max imperfect length value**
  > Changes the default for the inline edits experiment “max imperfect agreement length” from 5 to 1. This tweaks how conservative the feature behaves by default.
- [#321078](https://github.com/microsoft/vscode/pull/321078) **AH: replace agentSdks {url, sha256} with {urlTemplate}**
  > Switches agent SDK downloads to use a runtime `urlTemplate` with per-host `sdkTarget` selection and separate cache dirs. This improves reliability for macOS Universal and Linux libc variants.
