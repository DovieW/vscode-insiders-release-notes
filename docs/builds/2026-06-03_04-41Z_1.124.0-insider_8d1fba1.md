## ✨ NEW

- [#319671](https://github.com/microsoft/vscode/pull/319671) **cli: support pinning initial agent host version for upgrade testing**
  > Adds a VSCODE_CLI_INITIAL_AH_VERSION env var so the CLI can start the agent host from a pinned older version, making upgrade testing possible locally without changing real upgrade behavior.
- [#316473](https://github.com/microsoft/vscode/pull/316473) **Browser: Playwright API metrics**
  > Adds telemetry for the Integrated Browser Playwright tool, including run success/failure, duration, and which page API methods were called, to better understand real usage.
- [#319432](https://github.com/microsoft/vscode/pull/319432) **Add experiment flag to hide model name in chat auto mode**
  > Adds an experiment flag to hide the underlying model name in chat auto mode, showing “Auto” (plus credits/multiplier) instead to test whether it affects users switching away from auto.
- [#318822](https://github.com/microsoft/vscode/pull/318822) **[Codex] Add app-server agent host provider**
  > Introduces the Codex agent-host provider and wires it into workbench/session runtime (providers, session lifecycle, routing, and tests), enabling “Codex - Agent Host” sessions.
- [#319653](https://github.com/microsoft/vscode/pull/319653) **sessions: experimental setting for local agent host as default provider**
  > Adds an experimental setting (chat.agentHost.defaultSessionsProvider) and an ordering mechanism for session providers so the local agent host can appear first in the Agents window.
- [#319480](https://github.com/microsoft/vscode/pull/319480) **Browser: History**
  > Adds a per-session integrated browser history feature, including a stored history model, URL bar recents/history suggestions, and a “Show History” action with related UI changes.
- [#319628](https://github.com/microsoft/vscode/pull/319628) **Suport CLI context size picking**
  > Adds support for choosing a context size in the Copilot CLI by introducing contextSize selection and propagating it as contextTier through session setup and requests.

## 🐛 FIXES

- [#319663](https://github.com/microsoft/vscode/pull/319663) **Enhance logging for autorun registration and session disposal in chat service**
  > Improves chat service logging and adds a guard to stop stale model→view autoruns from overwriting the active session’s selected model state; intended to prevent subtle state glitches.
- [#319455](https://github.com/microsoft/vscode/pull/319455) **agentHost: keep SSH connection registered after incompatible handshake**
  > Fixes SSH “Update Server” upgrades when the initial handshake fails due to an unsupported protocol version by keeping an incompatible managed connection alive for the upgrade transport.
- [#319660](https://github.com/microsoft/vscode/pull/319660) **Make browser sharing availability contextual to the active session**
  > Makes “Share with agent” availability depend on the active session type in the Agents window, instead of a general config gate, so sharing is offered only when it can work.
- [#319654](https://github.com/microsoft/vscode/pull/319654) **Browser: update suggestions dynamically as tabs change**
  > Fixes stale “Open Tabs” URL bar suggestions in the Integrated Browser by refreshing suggestion lists dynamically as tabs and editor groups change.
- [#319638](https://github.com/microsoft/vscode/pull/319638) **Memoize getFirstNonCopilotModel in scenario automation endpoint provider**
  > Memoizes the “first non-copilot” model lookup for scenario automation runs and invalidates it when chat models change, cutting repeated empty-selector fan-out work.
- [#319619](https://github.com/microsoft/vscode/pull/319619) **Increase quick pick height for browser URL bar**
  > Adjusts anchored quick input sizing so the browser URL bar quick pick can show more items in overlay mode, improving usability in constrained layouts.
- [#319453](https://github.com/microsoft/vscode/pull/319453) **vscode-api-tests: use explicit \`types\` instead of \`typeRoots\`**
  > Hardens vscode-api-tests TypeScript config by switching from typeRoots auto-discovery to an explicit types list (node, mocha), avoiding build flakes when @types are hoisted.
- [#319484](https://github.com/microsoft/vscode/pull/319484) **Redact error callstacks per-line to avoid wiping the entire stack**
  > Improves telemetry redaction for error callstacks by redacting per line instead of collapsing the whole stack into a single &amp;lt;REDACTED&amp;gt; marker when one line matches.
- [#319620](https://github.com/microsoft/vscode/pull/319620) **fix: default tokenizer to O200K when server omits it (fixes #319618)**
  > Fixes a crash when the server omits the tokenizer field by defaulting to the O200K tokenizer type, preventing “Unknown tokenizer: undefined” errors.
