## Summary

- Sessions: let the Sessions folder “pill” open the managed Files editor in single-pane layout while keeping the Files view visible—maintains existing Files-only behavior elsewhere.
- Modern UI tabs: add new theme color tokens (active/hover/inactive/action) for finer tab styling, plus reserve the close-button area so it won’t overlay filenames.
- Omni Chat: restrict Omni Chat to the Agents window and improve routing/UX; also fix Omni Chat input resizing and keep session title in sync.
- Agent Host: add `chat.agentSessions.showExternal` to control discovery/display of external Agent Host sessions, preserving unread/ownership when rediscovering.
- Fixes: prevent first-send race for sessions, show live last-turn changes in the Changes pill, and expand collapsed diffs when revealing changed files.
