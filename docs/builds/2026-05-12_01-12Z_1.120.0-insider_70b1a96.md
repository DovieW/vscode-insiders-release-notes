## 🐛 FIXES

- [#315828](https://github.com/microsoft/vscode/pull/315828) **terminal: fix Linux sandbox wrapper env assignment**

- [#315889](https://github.com/microsoft/vscode/pull/315889) **Dynamically manage local harness registration based on configuration changes**
  > Makes the Agents “Local” customization harness register and unregister live when sessions.chat.localAgent.enabled changes. Users see the Customizations UI match the setting without reload.
- [#315868](https://github.com/microsoft/vscode/pull/315868) **[cherry-pick] fix: background todo agent prompt correctness and noise reduction**
  > Improves the background todo agent prompt to produce correct todo lists and cut noisy tool calls. Also adjusts how tool calls count toward running the agent so progress is detected reliably.
- [#315701](https://github.com/microsoft/vscode/pull/315701) **Fix for using reopen-with on dirty untitled doc incorrectly dropping …**
  > Prevents data loss and duplicate tabs when using Reopen With on dirty untitled docs handled by custom editors. Broadens open detection and moves a model revert to happen after untitledDocumentData arrives.
- [#315859](https://github.com/microsoft/vscode/pull/315859) **[cherry-pick] chat: disable agents window actions when agent mode is disabled**
  > Disables and hides “Open in Agents” / “Open Agents Window” when chat.agent.enabled is false. This prevents users from seeing actions that won’t work.
- [#315805](https://github.com/microsoft/vscode/pull/315805) **[cherry-pick] github-auth: revert sessions-specific auth branding**
  > Reverts sessions-specific auth branding by removing the sessions app_is_sessions handling and related assets/config. Restores the simpler auth flow since agents are no longer separate.
- [#315794](https://github.com/microsoft/vscode/pull/315794) **Disable Copilot Memory and remove github.copilot.chat.copilotMemory.enabled setting**
  > Disables Copilot Memory on release/1.120 by removing the user setting and forcing the checks off. Users with the setting enabled will just get an “unknown setting” warning; no memory features will run.
- [#315809](https://github.com/microsoft/vscode/pull/315809) **[cherry-pick] sessions: default pre-cutoff sessions to read to avoid unread badge flood on upgrade**
  > Stops unread badge floods after upgrade by treating pre-cutoff sessions as read by default. Only sessions updated after the cutoff will show as unread, and markUnread won’t affect old ones.
- [#315707](https://github.com/microsoft/vscode/pull/315707) **Improved git state computation for local sessions**
  > Improves local session git state computation so Changes view shows more accurate per-file stats. Uses diffBetweenWithStats2 when possible and fills gaps for files not covered by the diff.
- [#315705](https://github.com/microsoft/vscode/pull/315705) **Disable the local harness by default**
  > Disables the Local Agents window harness by default on the 1.120 stable timeframe. It stays behind the sessions.chat.localAgent.enabled setting for opt-in.
