## Summary

- Agents Window: add “Show Editor” action to restore the editor area after hiding it, with corrected placement/icons and browser-tab fallback behavior.
- Voice Mode: preserve voice targeting when creating new chat sessions, improve voice approval matching, and fix delayed voice playback when reopening sessions.
- Remote/Agent Host security &amp; reliability: verify SSH host keys for remote Agent Host connections and hard-fail on mismatches (with “Forget SSH Host Key”).
- Chat/Agents workflow: add session router service plus lightweight chat session history reads to reduce cache loading while improving session selection behavior.
- Auxiliary windows: add `IAuxiliaryWindow.setBounds` so auxiliary windows can be repositioned/resized after creation (including native Electron support).
