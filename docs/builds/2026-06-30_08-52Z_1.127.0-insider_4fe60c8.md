## Summary

- Add the Kimi prompt to the product UI.
- Agents window: experiment setting `workbench.editor.markdownDefaultEditorInAgentsWindow` lets you control the default `*.md` editor (off by default).
- Fix Sessions picker closing immediately after releasing Ctrl when opened with Ctrl+R; picker now stays open until you finish navigation/selection.
