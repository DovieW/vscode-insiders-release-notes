## Summary

- Extensions auto-update: default extensions.autoUpdateDelay increased from 2 to 12 hours for users who haven’t customized it (#331468).
- Sessions: GitHub PR/issue items opened from sessions now use the GitHub Pull Requests extension when possible, with cleaner PR/issue editor layout (#331471).
- Chat UX: mouse Back in stacked chat sessions returns you to the agent sessions list (keeps existing behavior for side-by-side/edge cases) (#331126).
- Chat: dictation no longer requires paid Copilot entitlement—local works on-device; cloud still requires GitHub sign-in (#331321).
- Fix: Omni chat input resizing during paste/history navigation no longer clips lines (measures height synchronously from the input) (#331233).
- Fix: external session visibility is faster and corrected when toggling chat.agentSessions.showExternal by reconciling in a single catalog pass (#331472).
