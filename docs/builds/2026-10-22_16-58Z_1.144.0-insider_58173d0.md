## Summary

- Sessions: agent tools to read and reorganize the Sessions list (group/sort/filter, nesting, moving, collapsing) so agents can perform the same list actions as the UI.
- Agents: “Open Pull Request Changes” action on PR rows opens the PR’s multi-file diff directly in the multi-file diff editor.
- Computer Use: Agent Host can now prompt the user to enable Computer Use via an in-chat card (with reason) instead of requiring `/computer on`.
- Workbench: new auto-hide sash grippers (default on) with `workbench.sash.autoHideGrippers*` settings for less visual clutter while you work.
- Sessions fixes: preserve “This Computer” during composer/session restoration, restore no-workspace side pane per chat, and scope Canvas activity actions to the active chat.
- Chat: remote artifact videos now open with the correct remote resource authority (fixes Remote-SSH opening as local files).
