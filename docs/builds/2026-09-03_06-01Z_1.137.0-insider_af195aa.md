## Summary

- Agent Host debug log export: added a “Copy Path” action to quickly copy the exact ZIP path (desktop) or exported folder path (web).
- Sessions now show live remote connection state (download progress, offline/unreachable recovery, reconnect countdown) and can auto-start WSL hosts when opening chats.
- Workspace picker preview: consolidated GitHub and remote workspaces under a single “Remote” tab, with updated Issue/PR context and search UI.
- Chat: plugin update action moved to the Installed section (shown only when plugins exist) and improved tooltip/accessibility.
- Fixed Agent Host sandbox model fallback messaging and prevented editable confirmation UIs from running the original command after edits.
- Chat: deduplicated session widgets by target link so repeated messages to the same session don’t create multiple identical widgets.

## ✨ NEW

- [#334078](https://github.com/microsoft/vscode/pull/334078) **agentHost: Add copy path action to debug log exports**
  > Adds a “Copy Path” action to the Agent Host debug log export privacy warning, copying the exact ZIP path (desktop) or exported folder path (web). Helps users share exported logs quickly.
- [#334111](https://github.com/microsoft/vscode/pull/334111) **Agent Host: surface remote connection state in sessions**
  > Surfaces remote Agent Host connection state directly in the session UI (e.g., download progress, unreachable/offline recovery, reconnect countdown). Adds an option to auto-start WSL hosts when opening chats.
- [#334084](https://github.com/microsoft/vscode/pull/334084) **sessions: Consolidate GitHub and remote workspace options**
  > Adds an experiment-controlled preview to consolidate GitHub and remote workspaces under a single “Remote” tab in the workspace picker, and adjusts Issue/PR context flow and search UI accordingly.
- [#334118](https://github.com/microsoft/vscode/pull/334118) **Show harness and workspace in customizations modal title**
  > Updates the Agent Customizations modal title to show the active harness and workspace in a lighter “(harness · workspace)” format, updating reactively as targets change.

## 🐛 FIXES

- [#334151](https://github.com/microsoft/vscode/pull/334151) **agentHost: drain providers during standalone shutdown**
  > Fixes standalone Agent Host shutdown ordering to stop/drain ingress, wait for providers to stop, and flush state before disposal. Reduces session listing/race flakes during graceful restarts.
- [#333973](https://github.com/microsoft/vscode/pull/333973) **Enhance agent merge widget for accessibility and interaction**
  > Improves the Agent Merge widget’s accessibility and interaction so review status is easier to scan and keyboard/focus behavior is clearer. Mainly a UI/interaction correction plus test/fixture updates.
- [#334133](https://github.com/microsoft/vscode/pull/334133) **Surface sandbox model fallbacks and honour confirmation editability**
  > Fixes sandbox model fallback messaging and prevents mislabeling context tiers; also makes agent-host confirmation UIs non-editable to avoid running the original command after edits.
- [#334124](https://github.com/microsoft/vscode/pull/334124) **Preserve customization roots during provisional sessions**
  > Preserves customization “roots” during provisional Agent Host sessions by using the generation’s working directories until real session state arrives. Prevents early customizations from being omitted in first-request...
- [#334125](https://github.com/microsoft/vscode/pull/334125) **Classify worked items as session artifacts**
  > Adjusts session artifact classification so worked-on items are treated consistently as artifacts, even when the session didn’t create them. Includes schema alignment and regression coverage for the guidance.
- [#334086](https://github.com/microsoft/vscode/pull/334086) **chat: Move plugin update action to installed section**
  > Moves the “check for and apply updates” action into the Installed section and only shows it when at least one plugin is installed. Also clarifies the tooltip and accessible label.
- [#334123](https://github.com/microsoft/vscode/pull/334123) **chat: deduplicate session widgets by target**
  > Deduplicates chat session widgets by their target link so repeated messages to the same session don’t render multiple identical widgets. Different session targets still render separate widgets.
- [#333869](https://github.com/microsoft/vscode/pull/333869) **Allow semantic search toggle for search subagent**
  > Adds a feature-flag gate so semantic search is only enabled for the Search subagent, avoiding unreliable behavior from the semantic search tool. Default behavior remains unchanged elsewhere.
