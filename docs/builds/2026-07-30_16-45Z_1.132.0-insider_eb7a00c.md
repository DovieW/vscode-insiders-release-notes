## Summary

- Copilot Chat: improve recovery safety by adding a Kimi K3 biosecurity refusal policy, plus bumping to Copilot Chat 0.59.1 with recovery regression fixes.
- Copilot Agent Host: strengthen multi-root support and migration defaults; sync eligible `.mcp.json` servers across workspace roots and enable Agent Host migration by default (web-remote uses Agent Host).
- Voice Mode &amp; dictation: refined microphone context menus and onboarding preview behavior (better labels, accessibility, and fewer confusing UI states).
- Chat/Markdown: fix chat word-wrapping (“wordwarp”), apply smaller Markdown edits to improve correctness/perf, and stop auto-expanding non-terminal tool failures.
- Agent Host stability fixes: prevent worktree include file path collisions, preserve terminal cwd for unsandboxed retries (Linux/spaces), and fix message merging so signed “thinking” blocks aren’t spliced.
