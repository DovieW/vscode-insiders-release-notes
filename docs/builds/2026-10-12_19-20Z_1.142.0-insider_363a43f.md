# 2026-10-12 - 19:20Z

Commit: [363a43f](https://github.com/microsoft/vscode/commit/363a43fb9eb3551f66ff60d5d12d14d9daa02300) · Previous: [ff00e78](https://github.com/microsoft/vscode/commit/ff00e788322523ee1e9e8ee2c9bb4b89af93a3c2) · Compare: [GitHub](https://github.com/microsoft/vscode/compare/ff00e788322523ee1e9e8ee2c9bb4b89af93a3c2...363a43fb9eb3551f66ff60d5d12d14d9daa02300)
Version: `1.142.0-insider` · Branch: `main` · Upstream: [microsoft/vscode](https://github.com/microsoft/vscode)


## Summary

- Added a `chat-customizations` URL protocol handler so links open the right Chat Customizations page and can prefill the search query.
- Agent Host now preserves writable session compatibility across downgrade/upgrade, preventing sessions from becoming unopenable after reverting.
- Fixed Agent Host catalog/chat-archive state retention when provider listings omit sessions, making previously excluded sessions reversible.
- Agent Host preserves client tools across nested session unsubscribe, only releasing tools after the client leaves the entire parent session.
- Preserved the default chat identity during partial summary updates (when `defaultChat` is missing), avoiding unwanted active-chat switching and layout blinking.
- Canvas storage now uses Copilot home storage instead of `VSCODE_CANVAS_DATA_DIR` to prevent data loss across updates/hosts.

## ✨ NEW

- [#341134](https://github.com/microsoft/vscode/pull/341134) **[cherry-pick] Add Chat Customizations protocol handler**
  > Adds a `chat-customizations` URL handler so links can open the right Chat Customizations page and optionally prefill its search query. Includes supported page types and targeted tests.

## 🐛 FIXES

- [#341086](https://github.com/microsoft/vscode/pull/341086) **[1.142] agentHost: preserve writable session downgrade compatibility**
  > Backports Agent Host session storage compatibility so downgrading doesn’t make sessions unopenable. Preserves readable session identities and catalog behavior across the downgrade/re-upgrade window.
- [#341046](https://github.com/microsoft/vscode/pull/341046) **[cherry-pick] agentHost: keep catalog data when a provider listing omits a session**
  > Prevents `providerAbsent` exclusions from deleting a session’s catalog data and chat archive. Excluded sessions are now reversible without losing stored state.
- [#340998](https://github.com/microsoft/vscode/pull/340998) **[cherry-pick] agentHost: retain client tools across nested session unsubscribe**
  > Keeps client tool contributions available while any parent or sibling nested session subscription is still active. Only releases tools after the client leaves the entire parent session.
- [#340969](https://github.com/microsoft/vscode/pull/340969) **sessions: Preserve default chat identity in partial summary updates**
  > Preserves the advertised default chat when Agent Host sends partial summary updates that omit `defaultChat`. This avoids unwanted active-chat switching and layout blinking.

## ⬆️ UPGRADES

- [#341119](https://github.com/microsoft/vscode/pull/341119) **[cherry-pick] canvases: replace VSCODE\_CANVAS\_DATA\_DIR with Copilot home storage**
  > Switches canvas extension private storage from the VS Code-specific `VSCODE_CANVAS_DATA_DIR` to host-neutral Copilot home storage. This prevents data loss across plugin updates and works across Copilot hosts.

## 🛠️ DEVELOPER UPDATES

- [#341051](https://github.com/microsoft/vscode/pull/341051) **[cherry-pick] Fix the session removal bug causing many flaky tests**
  > Fixes a session removal bug that could be overwritten by concurrent summary persistence, causing flaky behavior. Adds regression coverage for concurrent updates.
- [#340958](https://github.com/microsoft/vscode/pull/340958) **docs: unwrap Agent Host prose**
  > Unwraps/rewraps Agent Host and related documentation prose for consistent Markdown formatting (one paragraph per source line). No functional code changes; it’s docs-only maintenance.
