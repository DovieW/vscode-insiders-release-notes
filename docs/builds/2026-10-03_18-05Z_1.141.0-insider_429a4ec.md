## Summary

- Sessions: guided “bakeoff” setup workflow to compare agent models (Attempts → optional Judge → optional Synthesizer), with a setting to open the comparison grid before starting attempts.
- Chat: enrich GitHub reference previews with better related-entry context and add pill actions (Copy URL/path/relative path) for faster reuse.
- Agent Host chats: stream attached background shell output live and expose it in Accessible View; users can follow long-running command output without switching tools.
- Chat: preserve request-start context on terminal telemetry and fail when the selected model is unavailable to avoid silent fallback/billing with the wrong model.
- Fixes: restore peer chats after session refresh, preserve chat transcript order when refreshing history, and fix browser double-navigations for `window.open` popups.
