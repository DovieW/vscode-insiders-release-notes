## Summary

- Add a configurable “Live Browser” pill above the chat input for agent-host sessions, showing the last URL and letting you open it in the integrated browser (default off).
- Codex agent-host upgrades: session forking, improved subagent rendering, unified permission chips, and clearer auto-review denial surfacing.

- Improve local→agent-host handoff with an in-place switch (less jarring UI) and better imported session fidelity; also fix archived state using server truth only.
