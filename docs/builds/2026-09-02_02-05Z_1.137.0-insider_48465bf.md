## Summary

- Browser: support tracking the host session id separately from agentic ownership, enabling future correct association of Agent Window sessions with the right browser host.
- Show remaining turns to execution subagents and stop tool calls on the final iteration, improving reliability/clarity of multi-subagent execution.
- Sessions: enable the application badge in non-stable builds and include blocked sessions needing input/failing checks in the badge count.
- Browser: make browser view ownership mutable across main/renderer processes, with change events and inherited ownership for newly opened child views.
- Agents: add commit operation directly into the Changes view for easier commit-from-diff workflows.
