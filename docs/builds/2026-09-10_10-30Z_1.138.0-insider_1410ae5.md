## Summary

- chat: Make “Mark as Done” the default chat session archive wording (and “Restore”), improving clarity in the experimental archive action UI.
- agentHost: Enable Agent Host Codex harness by default in Insiders (kept off in Stable), and prefer the Agent Host Codex implementation in regular editor windows.

- sessions: Add opt-in automatic cleanup for merged-PR sessions via the archive/mark-as-done nudge, including a keyboard-accessible “Configure Automatic Cleanup” action.
