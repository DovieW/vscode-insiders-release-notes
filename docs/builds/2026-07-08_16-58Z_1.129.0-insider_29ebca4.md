## Summary

- Add `github.copilot.chat.preferLongContext.enabled` to control how free long-context models behave (restore shorter context option when off).
- Improve chat “turn changes” UI with checkpoint-style summaries and a per-file Preview action, making diffs easier to scan during Agents/Copilot chat.
- Voice: fix a TTS bug where switching between multiple voice chat sessions could cause responses to stay silent.
- Agents window: open the Changes pill as a live multi-diff editor for the last turn (no full-session rerun), reusing the editor as diffs stream.
- NES: add experimental control to show more context lines in the long-distance hint preview (`editor.inlineSuggest.edits.longDistanceHintContextLineCount`). Default remains single-line.
- Fix several Agents/Workbench UI issues: correct multi-diff header overlap, avoid duplicated “Open File”, and fix blocked-sessions indicator blinking on session switch.
