## Summary

- Copilot Agent Host now receives the workspace’s VS Code Trust state for the working folder, enabling trusted repos to load runtime plugins/hooks/MCP and auto-install enabled plugins.
- Chat: added side chats in normal editor windows (with an “Ask in Side Chat” context menu) so you can branch without changing the original conversation.
- Sessions UI: session hovers now show clickable “Created in” application provenance and jump/focus the “Created In” filter for easier navigation.
- Chat: editor context menu gains Working Set review controls (“Keep and Undo” and “Show Pill”), and docked notification focus/outline behavior is fixed for better accessibility.
- Fixes MCP integration issues: UTF-8 encoding for MCP URI template values and correct routing so disabling MCP servers in ~/.copilot/mcp-config.json reaches the Agent Host.
