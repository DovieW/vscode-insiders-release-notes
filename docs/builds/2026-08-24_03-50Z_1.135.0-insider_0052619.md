## Summary

- Float Agents chat status pills above the chat input (instead of inside it) for better readability and smoother scrolling in Agents.
- Default `chat.agentSessions.showExternal` to recent external sessions (experimental) instead of showing none, with automatic overrides without renaming the setting.
- Agents/Agents Window: generate titles for “untitled” external sessions using the user’s first prompt, so the session list shows meaningful names.
- Windows/Linux launch skill: add `--skip-prelaunch` fast path and report startup timing phases (profile, pre-launch, CDP ready, total) to debug/optimize relaunches.
- Mobile: keep the Agents chat composer above the virtual keyboard on iOS/Android via visualViewport relayout on resize.
