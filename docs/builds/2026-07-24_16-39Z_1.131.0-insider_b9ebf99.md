## Summary

- Agent Host Codex harness: support using an OpenAI/ChatGPT subscription (instead of only Copilot), via codexUsageSource.
- Agent Host sessions can now send/restore browser element attachments (e.g., text variables, chat history) to preserve richer context.
- New Agent session UI adds a “Changes” tab for draft sessions, including provisional changesets for better workflow review.
- Fixes Agent harness model picker switching by preserving/restoring the correct model state when changing harness session pools.
- Improves Agent Host Git branch discovery with structured metadata and better filtering/sorting/completions for refs.
- Fixes multiple UI/session issues: ARM64 native binary resolution in packaged builds, stale animated session icons, and hidden Automations list layout.

## ✨ NEW

- [#327290](https://github.com/microsoft/vscode/pull/327290) **agentHost: support OpenAI subscriptions in Codex**
  > Adds support for using an OpenAI/ChatGPT subscription in the Agent Host Codex harness via codexUsageSource. Copilot remains the default, with separate provider launch handling.
- [#327303](https://github.com/microsoft/vscode/pull/327303) **Support element attachments over agent host**
  > Lets Agent Host send and restore browser element attachments (like text variables and chat history). This ensures agent context includes the element content during restores.
- [#327295](https://github.com/microsoft/vscode/pull/327295) **AgentHost - improvements to the method to get repository branches**
  > Expands Agent Host Git branch discovery with structured metadata and configurable ref queries. Improves filtering, sorting, and completion results for branch/ref lookup.
- [#327265](https://github.com/microsoft/vscode/pull/327265) **new icon for aquarium**
  > Adds a new aquarium icon style using fish “mood” states that change over time. It includes updated rendering/styling, accessible labels, and tests for the hunger transitions.
- [#327189](https://github.com/microsoft/vscode/pull/327189) **Agent - show "Changes" tab for new session**
  > Adds a “Changes” tab for new (workspace draft) Agent sessions, alongside Files. It also supports provisional changesets and updates the related session-layout logic and tests.

## 🐛 FIXES

- [#327302](https://github.com/microsoft/vscode/pull/327302) **fix: prefer unpacked node\_modules for native binaries**
  > Prefer unpacked native binaries from node_modules.asar.unpacked, with a fallback to plain node_modules. This fixes ARM64 Linux packaged resolution failures.
- [#327296](https://github.com/microsoft/vscode/pull/327296) **Fix harness model picker switching**
  > Fixes model picker state when switching harness session pools by seeding the destination session type and revalidating/restoring models. Includes coverage for delayed model loading.
- [#325985](https://github.com/microsoft/vscode/pull/325985) **fix performance regression caused by modern UI styles**
  > Removes an expensive Explorer-wide CSS :has() selector to avoid UI performance invalidation. Keeps behavior the same while reducing style overhead.
- [#327272](https://github.com/microsoft/vscode/pull/327272) **fixes https://github.com/microsoft/vscode/issues/327221**
  > Fixes stale animated session status icons when virtualized session rows get recycled. Icons now reset/snaps correctly based on session identity.
- [#327271](https://github.com/microsoft/vscode/pull/327271) **Remove archived sessions from user-created groups**
  > When a session is archived, it’s removed from any user-created groups it belongs to, and restoring doesn’t bring back the group. Also deletes now-empty groups and improves empty-group hover guidance.
- [#327200](https://github.com/microsoft/vscode/pull/327200) **Fix sub agent credit count not being accounted for**
  > Fixes an issue where sub-agent credit counts weren’t added into the parent session totals. This also updates the session-cost UI and adds regression tests to prevent repeats.
- [#327254](https://github.com/microsoft/vscode/pull/327254) **Fix hidden Automations list layout**
  > Fixes the Automations list layout when the section is hidden, preventing zero-height/incorrect row measurements. Remeasures and updates properly when the panel becomes visible, with added regression tests.
