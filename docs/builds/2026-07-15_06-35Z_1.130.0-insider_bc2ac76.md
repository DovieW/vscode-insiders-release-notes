## Summary

- Support additional Grok model capabilities for multi-string replacement in the chat editor routing, enabling the feature on more Grok-family models.
- Add voice barge-in so new speech can interrupt queued/playing assistant audio for a more responsive voice experience.
- Control Voice Mode via experiment rollout by extending `agents.voice.enabled` to support `mode: 'auto'`.
- Fix Agents window single-pane layout to stop force-reopening managed tabs and remove the docked detail panel bottom gap.
- Improve voice Q&amp;A UX: show “Answered” (not “Skipped”) for externally-answered questions and persist the state across reloads.
- Fix telemetry truncation by chunking large diffsJSON payloads across multiple telemetry columns.
