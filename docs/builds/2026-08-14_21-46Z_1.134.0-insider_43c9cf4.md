- [#330965](https://github.com/microsoft/vscode/pull/330965) **Fix Chat panel progress badge alignment**
  > Fixes Chat panel progress badge alignment by centering labeled progress indicators in the compact 16x16 container. Compact icon and numeric badges keep their existing layout.
- [#330759](https://github.com/microsoft/vscode/pull/330759) **chat: identify managed settings client via query parameters**
  > Updates managed settings client identification to use query parameters instead of headers, so the settings service can correctly fail closed with older clients. Includes test updates and diagnostics adjustments.
- [#330930](https://github.com/microsoft/vscode/pull/330930) **fix md resize causing wrong calculated position**
  > Fixes Mermaid diagram positioning when the containing chat UI resizes by switching to container-level resize observation (ResizeObserver). Position is recalculated when dimensions change.
- [#330919](https://github.com/microsoft/vscode/pull/330919) **automations: Handle edit dialog failures**
  > Handles automation edit dialog failures by logging them and showing them through the existing automation update error dialog. Adds regression coverage to ensure the error path is exercised.
- [#330923](https://github.com/microsoft/vscode/pull/330923) **Guard RPC proxies against becoming thenables**
  > Guards RPC proxy objects against being treated as thenables by preventing `then` from being synthesized. This avoids deadlocks where `await` would hang due to a bogus remote `then` call.
- [#330656](https://github.com/microsoft/vscode/pull/330656) **Hide breadcrumbs in compact windows**
  > Hides the editor breadcrumbs when the window uses compact title bar mode, then restores them when leaving compact mode without changing your breadcrumbs setting.
- [#330910](https://github.com/microsoft/vscode/pull/330910) **agentHost: anchor the side chat boundary to the inherited turn id**
  > Fixes side chat transcript boundary anchoring by using an inherited turn id, preventing growth from hiding user turns in side chats.
- [#330737](https://github.com/microsoft/vscode/pull/330737) **Revert to showing all context size options**
  > Reverts the Copilot context-size picker to show both default and long-context options again, removing the preference setting that hid the smaller choice.
- [#330884](https://github.com/microsoft/vscode/pull/330884) **Further Cleanup Model restoration logic**
  > Improves chat model restoration by tracking “intended model” on the conversation, preserving inline edit selections during resubmission.
- [#330897](https://github.com/microsoft/vscode/pull/330897) **chat: preserve active input flow for side questions**
  > Keeps the active chat approval/input flow open when a user submits a side question with /btw, fixing broken concurrent silent slash command routing.
