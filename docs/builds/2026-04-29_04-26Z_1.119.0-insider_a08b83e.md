## 🐛 FIXES

- [#313149](https://github.com/microsoft/vscode/pull/313149) **Browser: better window lifecycle handling**
  > Moves browser view reload/workspace cleanup to the main process so browser views are always hidden/disposed when the window reloads or switches workspaces. Users benefit from fewer stale/incorrect browser views.
- [#313138](https://github.com/microsoft/vscode/pull/313138) **OTel: include tool parameters and emit tool definitions on child chat spans**
  > Improves OpenTelemetry tracing for chat tools by emitting complete tool definitions, including input parameters, on both root and per-model child spans. Better trace viewers and debugging for tool calling.
- [#313013](https://github.com/microsoft/vscode/pull/313013) **ci: start the full app to verify signature on macOS**
  > Updates macOS CI to start the signed VS Code app and wait for profiling output, improving confidence that required signed processes won’t be killed at runtime. CI reliability improvement, not app behavior.
- [#313106](https://github.com/microsoft/vscode/pull/313106) **terminalChat: fix OutputMonitor dispose race that stalls run\_in\_terminal**
  > Fixes a dispose-time race in terminal OutputMonitor where waiting for `onDidFinishCommand` could hang. This prevents `run_in_terminal` calls from stalling until a long timeout.
- [#312838](https://github.com/microsoft/vscode/pull/312838) **Allow write to /tmp when allow all commands in session**
  > When users allow all commands for a session, `/tmp` file writes no longer block auto-approval. Helps terminal auto-approve work smoothly on both macOS and Windows workflows.
- [#313129](https://github.com/microsoft/vscode/pull/313129) **Fix reasoning bunching on agent host session restore (live path)**
  > Fixes a warm-restore ordering issue where agent “reasoning” could bunch at the top instead of interleaving with tool calls. Adds regression tests to prevent the same rendering break.

  > Disables the core ask-questions tool when permission level is autopilot, so the agent doesn’t ask user-facing questions that could be auto-answered incorrectly. Prevents autopilot misbehavior.
- [#313093](https://github.com/microsoft/vscode/pull/313093) **Fix missing model picker multipliers**
