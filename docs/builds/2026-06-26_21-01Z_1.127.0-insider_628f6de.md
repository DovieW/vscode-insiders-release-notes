# 2026-06-26 - 21:01Z

Version: `1.127.0-insider` · Branch: `main` · Upstream: [microsoft/vscode](https://github.com/microsoft/vscode)


## Summary

- Deprecates the built-in internal Ollama BYOK provider in favor of the official Ollama extension, including migration links and a one-time chat notification for users using the deprecated provider.
- Integrated Browser chat tools: moves out of “experimental” by removing experimental metadata and the preview-account policy gating for broader availability.
- Chat model picker: Restricted Mode now always takes precedence over live agent-host/BYOK models, with clearer restricted messaging and no dead search/filter controls.
- Chat formatting fix: require double tildes for strikethrough so single tildes render as literal text (prevents Markdown rendering regressions).
- Copilot cloud sessions list: shows only real cloud coding-agent tasks and maps idle/waiting states to the correct UI statuses.
- Local agent usage: shows subagent (subagent) credits/cost totals in tool hovers by forwarding and persisting subagent credit usage.
