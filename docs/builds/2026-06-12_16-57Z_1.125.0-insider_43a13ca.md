  > Improves Agents window session type selection by tracking explicit user picks separately from the folder’s preferred default type. Prevents observed sessions from overwriting the user’s preference.
- [#320664](https://github.com/microsoft/vscode/pull/320664) **Block auto-approved file-write redirection to env-var (%) paths**
  > Hardens terminal command auto-approval against file-write redirection to Windows `%...%` environment-variable paths, similar to existing `~` handling. Adds regression tests for bash and pwsh cases.
- [#321140](https://github.com/microsoft/vscode/pull/321140) **Agents - show persistent state when switching between sessions**
  > Keeps cached/persisted Agent Host changeset file lists visible when switching between sessions instead of showing a loading state. Reduces flicker and avoids losing previously-known content.
- [#321138](https://github.com/microsoft/vscode/pull/321138) **fix: guard against missing voiceWsUrl in voice client**
  > Adds a guard in Voice client startup to avoid creating a WebSocket with an empty URL when voiceWsUrl isn’t configured. Logs a clear error and prevents the mic button from silently doing nothing.
- [#321131](https://github.com/microsoft/vscode/pull/321131) **disable the color decorators in the output view**
  > Disables color decorators in the Output view editor so color swatches/inline decorations don’t appear in Output text. Keeps Output content clean and predictable.
