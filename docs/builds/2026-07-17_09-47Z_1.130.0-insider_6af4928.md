## Summary

- Add on-device chat dictation (speech-to-text) with mic button, live transcript insertion, Whisper model size selection, and first-use download progress.
- Enterprise governance for MCP servers: new allowed/denied policies (by name, URL pattern, command) enforced at install and runtime with clear MCP UI errors.
- MCP agent-host enablement now supports persistent scopes (profile/workspace), applied before turns and tracked more precisely while keeping session-level controls.
- Voice/voice-agent reliability &amp; UX fixes: barge-in protocol and always-streaming mic, plus “connecting” spinner timeout and dropped narration recovery.
- Chat polish for risk &amp; defaults: show risk assessments on edit cards and add experimental `chat.defaultToCopilotHarness` to control new-user chat defaulting to Agent Host Copilot.
