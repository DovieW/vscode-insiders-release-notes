## Summary

- Chat context now includes your active rich Markdown selection (not just plain code selections), including in the Agents window, so responses match what you highlighted.
- Rich Markdown editor gains an Outline and heading breadcrumbs with live heading updates and reliable per-panel navigation state restore.
- External URI openers can now accept a `viewColumn` hint, letting extensions open links in the intended editor column (e.g., beside).
- Adds “Add Tab → Canvas” in the Agents window for extension-registered canvases tied to the current chat, opening stable, collision-safe instances.
- Agent Host disables the Copilot runtime’s search subagent by default, with an experimental opt-in setting to re-enable it.
