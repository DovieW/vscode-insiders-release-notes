## Summary

- Chat “Restore Checkpoint” (agent-host): added inline confirm/cancel when restoring would discard later edits, instead of only showing a modal.
- Agent Host: added per-subagent cost (credit) hover that persists across reloads so totals remain visible.
- Sessions: made “agent feedback” easier to discover with gutter affordance and a command to open feedback for the current line.
- New chat editors now restore the last-used non-local agent and that agent’s last-used model/configuration.
- Fix: “Open Host Settings” now works from the Command Palette by using the active session and hiding it when not applicable.

## ✨ NEW

- [#323050](https://github.com/microsoft/vscode/pull/323050) **AH: show better confirmation when there are edits**
  > Improves the Chat “Restore Checkpoint” flow for agent-host sessions by adding an inline confirm/cancel prompt when restoring would discard later edits, instead of relying only on a modal.
- [#322840](https://github.com/microsoft/vscode/pull/322840) **Add subagent cost hover for agent host**
  > Adds a hover in the subagent UI that shows each subagent’s accumulated credit (cost), including after reloads. Also persists the per-subagent credit totals to support the hover.
- [#319353](https://github.com/microsoft/vscode/pull/319353) **Add a "Sandboxing for terminal" toggle to the Default Approvals permission option**
  > Adds an experimental “Sandboxing for terminal” inline toggle to the Default Approvals permission option (for the local harness only). It wires the toggle to the sandbox enabled setting and updates picker UI/fixtures.
- [#323048](https://github.com/microsoft/vscode/pull/323048) **sessions: make agent feedback discoverable in editor**
  > Makes Sessions “agent feedback” easier to find by showing a clickable gutter affordance on hovered lines and adding a Command Palette command to open feedback for the current line.
- [#323046](https://github.com/microsoft/vscode/pull/323046) **sessions: cap user group sessions in list**
  > Extends the Sessions list “show more/show less” caps to user-created session groups, not just workspace groups. Find still bypasses capping, and new tests cover the behavior.
- [#323044](https://github.com/microsoft/vscode/pull/323044) **Open Host Settings in command palette**
  > Adds “Open Host Settings” to the Command Palette so you can trigger it from F1 instead of only the session menu. (No other behavior changes expected.)
- [#323011](https://github.com/microsoft/vscode/pull/323011) **chat: restore last-used agent and model for new chat editors**
  > New chat editors now reopen with the last-used non-local agent and that agent’s last-used model/configuration, instead of always starting with Local + Auto.

## 🐛 FIXES

- [#323061](https://github.com/microsoft/vscode/pull/323061) **Fix Open Host Settings command from the command palette**
  > Fixes “Open Host Settings” so it works from the Command Palette by using the active session when no session context is provided. Also hides/disabled the command when the active session isn’t an agent host provider.
- [#323059](https://github.com/microsoft/vscode/pull/323059) **Fix single tool calls getting stuck inside thinking parts**
  > Fixes a chat UI issue where a single tool call could get stuck inside a collapsed “thinking/Working” section. The promotion now works reliably across tool types and streaming timing.
- [#321969](https://github.com/microsoft/vscode/pull/321969) **fix: guard against missing default agent in chat sendRequest (fixes #321962)**
  > Prevents a chat crash when no default agent exists by removing the unsafe non-null assertion in `sendRequest`. Requests are now properly rejected instead of sending undefined agent data to downstream handlers.
- [#323034](https://github.com/microsoft/vscode/pull/323034) **Minor browser menu cleanup**
  > Cleans up Browser View UI by renaming “Manage Permissions” to “Site Permissions”, adjusting toolbar ordering, and fixing the macOS history shortcut to use ⌘Y.
- [#322974](https://github.com/microsoft/vscode/pull/322974) **Fix default model vendor resolution**
  > Fixes model configuration being saved to the wrong provider group when multiple groups share the same vendor. This prevents per-model settings from “disappearing” or landing in the wrong place.
- [#323031](https://github.com/microsoft/vscode/pull/323031) **Restore model config on reload for agent host**
  > Restores a remote chat session’s per-model configuration on reload (not just the model id). This keeps settings like model-specific options consistent across refresh.
- [#321861](https://github.com/microsoft/vscode/pull/321861) **Show session types as disabled with \`Sign in\` button when user is offline**
  > When signed out, session types that require entitlement now show as disabled with a Sign in prompt instead of looking selectable. Improves correctness of what users can start without signing in.
- [#323024](https://github.com/microsoft/vscode/pull/323024) **fix(oss): carry the cached NOTICE forward through multi-build CG outages**
  > Fixes OSS build pipeline NOTICE chain breaking during sustained Component Governance outages. Carry-forward builds now re-publish `ThirdPartyNotices.generated.txt` so downloads keep working.
- [#323029](https://github.com/microsoft/vscode/pull/323029) **sessions: respect hidden editor part when switching sessions**
  > Fixes a Sessions layout regression where switching back to a session would wrongly re-show the editor part. The UI now remembers per-session whether the editor part was intentionally hidden.
- [#323022](https://github.com/microsoft/vscode/pull/323022) **More comprehensive fix for Update button overlapping**
  > Prevents the title bar’s center-adjacent toolbar (like the update indicator) from pushing window controls off-screen when the window is collapsed. Adds overflow detection and hides the toolbar when needed.
- [#323026](https://github.com/microsoft/vscode/pull/323026) **sessions: keep focus in chat input when switching sessions**
  > Fixes a focus bug in the Agents window: switching sessions now keeps keyboard focus in the chat input instead of jumping to the editor/diff view.
- [#323025](https://github.com/microsoft/vscode/pull/323025) **AgentHost - refresh git state + operations when workspace files change**

- [#323017](https://github.com/microsoft/vscode/pull/323017) **Resolve context window for Auto in Agent Host**
  > Fixes the chat context-usage widget for Agent Host “Auto”/meta-models by resolving the context window from the effective model so the UI shows the right denominator.
- [#323021](https://github.com/microsoft/vscode/pull/323021) **sessions: always use close icon for chat tab close button**
  > Makes the Agents chat tab close button use a consistent close icon for both draft and committed chats, without changing the underlying delete/close behavior.
- [#323013](https://github.com/microsoft/vscode/pull/323013) **AgentHost - seed github state from the session database when restoring a session**
  > When restoring an Agent Host session, seeds GitHub summary metadata from the session database so restored sessions regain GitHub context immediately.
- [#322980](https://github.com/microsoft/vscode/pull/322980) **fix: guard WorkspaceTrustEditor.render against disposed instantiation service (fixes #322973)**
