## Summary

- Quick Open now supports hierarchical link targets (e.g., line ranges), opening them via the shared opener pipeline with Alt+Enter/side-open support.
- WSL/Git Bash/Cygwin on Windows: added a `copilot` launcher so `copilot` works like `code` from those shells.
