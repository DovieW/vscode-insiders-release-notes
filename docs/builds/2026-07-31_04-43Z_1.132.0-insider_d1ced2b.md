## Summary

- Upgraded the chat pet: new animations/variants and a “run on the go” mode with persistent settings and context-menu controls, coordinating visibility so it doesn’t block chat responses.
- Agents/Copilot sessions: browser activity now has its own pill above the chat input (and fixes narrow-layout pill overlap). Hidden chat transcripts now respect effective visibility.
- Added offline dictation model install support for registry-blocked networks (local package/dir install + UI when downloads fail, with validation and staged install/rollback).
- Cloud sandbox: added bounded retry logic plus outcome telemetry and credential refresh stop reasons to improve reliability and make failures easier to diagnose.
- Fixed multiple stability issues: browser overlap with modal webviews, several chat/notebook/decoration memory leaks, and inline chat terminal output resizing/reflow flicker.
