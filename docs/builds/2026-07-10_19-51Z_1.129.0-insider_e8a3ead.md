# 2026-07-10 - 19:51Z

## Summary

- Add a session provider/type picker to the Automations dialog, and persist the selected provider and session type in the automation configuration (#325223).
- Move Sessions “Create Pull Request” into the single-pane editor tabs title, with responsive icon-only collapse to improve layout (#325122).
- Fix chat model picker duplicates by enforcing consistent icon precedence (warning first), preventing repeated icons in the picker (#325200).
- MCP OAuth sign-in no longer loops for servers that grant scopes but advertise none; empty scopes are treated as authoritative (#325344).
- Fix Copilot Cloud Sessions stuck “in progress” behavior by improving stop/error messaging and preventing endlessly polled failed tasks (#325196).

## ✨ NEW

- [#325223](https://github.com/microsoft/vscode/pull/325223) **Add session provider picker to automations dialog**
  > Adds a session provider/type picker to the Automations dialog, replacing fixed defaults. The chosen provider and session type are saved into the automation configuration.
- [#325122](https://github.com/microsoft/vscode/pull/325122) **sessions: move Create Pull Request bar to the editor tabs title**
  > Moves the Sessions “Create Pull Request” button bar into the single-pane editor tabs title and makes it collapse to icon-only when space is tight. This improves layout in the single-pane Agents window.

## 🐛 FIXES

- [#325200](https://github.com/microsoft/vscode/pull/325200) **Prevent duplicate model picker icons**
  > Prevents duplicate icons in the chat model picker by applying a consistent precedence (warning icon first, otherwise provider icon). Includes regression coverage for the warning case.
- [#325344](https://github.com/microsoft/vscode/pull/325344) **MCP: fix infinite sign-in loop for servers that grant scopes but advertise none**
  > Fixes an MCP OAuth infinite sign-in loop when a server grants scopes but advertises none. Explicitly-set (even empty) token scopes are now treated as authoritative, with a regression test.
- [#325294](https://github.com/microsoft/vscode/pull/325294) **Record scheduled automation runs atomically**
  > Records scheduled automation runs more atomically by advancing schedule timestamps when the runner claims the run. This avoids reporting an overdue run before it’s actually taken, with added tests.
- [#325320](https://github.com/microsoft/vscode/pull/325320) **Remove agents.voice.turn.autoEndMode; derive auto-end from silenceMs/stopPhrases**
  > Removes the separate voice auto-end setting and instead computes backend auto-end mode from silenceMs and stopPhrases, so disabling those options reliably produces the expected end behavior.
- [#325238](https://github.com/microsoft/vscode/pull/325238) **MCP: preserve authorization server context on auth re-validation**
  > Preserves the MCP auth context (like authorization server/tenant and related IDs) during session re-validation, preventing silent token requests from targeting the wrong authority and causing server teardown.

## 🔨 REFACTORS

- [#325332](https://github.com/microsoft/vscode/pull/325332) **sessions: model docked (Changes/Files) editors as DockedEditorInput**
  > Introduces a shared `DockedEditorInput` base for docked Changes/Files editors and moves the reveal/collapse logic into the single-pane workbench using `instanceof`. Removes the old predicate-based reveal exclusion API.
- [#325316](https://github.com/microsoft/vscode/pull/325316) **Refactor copilot session launcher for cache handling**
  > Refactors Copilot BYOK session launcher logic to prefer cached models on resume while falling back to live enumeration when the cache is cold. Adds tests for warm/cold cache and create/resume behavior.

## ⬆️ UPGRADES

- [#325337](https://github.com/microsoft/vscode/pull/325337) **Add support for detecting latest sdk canary versions**
  > Updates the build pipeline to support a `latest-canary` sentinel for `VSCODE_SDK_CANARY_VERSION`, resolving it to the newest canary SDK. It also tags the build with the resolved version.

## 🛠️ DEVELOPER UPDATES

- [#325196](https://github.com/microsoft/vscode/pull/325196) **Improve Copilot Cloud Sessions error handling and messaging**
  > Improves Copilot Cloud Sessions error reporting so users see `Copilot stopped: &amp;lt;reason&amp;gt;` instead of an endless “in progress” spinner. Also prevents terminally failed tasks from being polled forever.
- [#325343](https://github.com/microsoft/vscode/pull/325343) **Skip flaky test (see #325266)**
  > Temporarily skips a flaky sandbox network smoke test referenced in #325266. No production behavior change—just stabilizing CI.
