## Summary

- Agents: support workspace-less automations in the Agents window (includes a “No workspace” target and headless runs), with persistence/migration and improved mobile/accessibility UX.
- Chat dictation: add opt-in on-device Nemotron (NeMo RNN-T) streaming, selectable via `chat.speechToText.model`, enabling more responsive incremental transcripts.
- Sessions: show per-file insertion/deletion stats in the single-pane Changes editor, including live updates and accessibility labeling.
- MCP: polish server list UI with semantic status icons and inline auth/output actions; fix virtual list sizing so items always scroll cleanly.
- Fixes: archived Agent Host chat sessions are now read-only, and Voice Mode no longer disconnects on cancel/keys or gets stuck when narration audio never starts.
