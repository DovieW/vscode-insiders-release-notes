## Summary

- CLI: add `code agent host --github-environment` to run a headless Agent Host registered as a GitHub Environment (handles device-code auth, registration, and lifecycle).
- Chat: configure Agent Host title generation with new `chat.agentHost.experimental.titleGeneration` `agentReview` strategy (seed title, then prompt agent to rename if needed).
- Mission Control: enable bulk structured user questions via Copilot SDK (`ask_user`) for Agent Host sessions, including session launch/resume and batched answer carousel UI.
- GitHub/Agent Host: improve Mission Control reliability by enforcing token expiration, preserving relay recovery across OS sleep, and enriching relay auth errors with the expected identity resource.
- MCP: fix `.mcp.json` URL handling to stop expanding variable-based URLs that Copilot runtime rejects (prevents MCP servers from being refused in Copilot sessions).
- Discovery: “Plugin marketplace” management moved into the Discovery quick pick with Add Marketplace + validation and enterprise allowlisting.
