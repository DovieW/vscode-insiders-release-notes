## Summary

- Create session from PR: add an Agents workflow to start isolated Sessions from GitHub pull requests, with a PR picker, tracked worktrees, and readiness progress/transcript state.
- Agent Host: require confirmation before running Codex/Agent Host server tools that need approval, preventing missed tool state from bypassing prompts.
- Voice Mode: remove unsupported voice file attachment actions/commands; improve connection failure reporting with clearer retry vs fatal messaging and avoid UI getting stuck on reconnecting.
- Fix excessive responsive toolbar relayout causing repeated rendering and high CPU.
- Sessions view: filter pre-existing PRs from folder-isolated sessions and avoid recursive list splice crashes; improve workspace preselection with session-history fallback.
