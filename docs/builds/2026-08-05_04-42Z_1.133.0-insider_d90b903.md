## Summary

- Forward `additionalDirectories` into the Copilot SDK session config for multi-root sessions, so the SDK session gets the extra workspace folders.
- Restrict terminal auto-approval related settings from being applied in untrusted workspaces to prevent unintended auto-approvals (incl. deprecated Agent setting).
- Agent Host debug log exports now include a fallback Copilot process log when no recent match is found, avoiding empty/incorrect exports.
- Register the `userDataSyncUtil` IPC channel for the Agents window entrypoint to prevent shared-process timeouts when the channel is missing.
- Multi-root session metadata no longer includes an obsolete `name` property (internal contract cleanup, no intended user-visible change).

- [#329069](https://github.com/microsoft/vscode/pull/329069) **Restrict terminal auto-approval setting in untrusted workspaces**
  > Restricts terminal auto-approval related settings from being applied from untrusted workspaces (including the deprecated Agent setting). Adds regression tests for trusted vs untrusted parsing behavior.
- [#329088](https://github.com/microsoft/vscode/pull/329088) **Include fallback Copilot process log in Agent Host debug exports**
  > Improves Agent Host debug log exports by adding a fallback selection when no recent log matches the session (or when there’s no active session context). Helps exports include the right log instead of nothing.
- [#329085](https://github.com/microsoft/vscode/pull/329085) **sessions: Register user data sync utility channel**
  > Registers the `userDataSyncUtil` IPC channel for the Agents window entrypoint, matching the normal desktop workbench. Prevents uncaught shared-process timeouts when the channel wasn’t available.
