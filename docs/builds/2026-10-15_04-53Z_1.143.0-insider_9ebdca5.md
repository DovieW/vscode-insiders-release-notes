## Summary

- Improved Automations “running” feedback with immediate starting-run state, refresh progress, and automatic view refresh while visible.
- Added an Editor Window “Canvas” submenu to open canvases after chat init, including stable canvas instances and documented keyboard navigation.
- Copilot Agent Host: added `chat.copilot.hydraFusion.enabled: 'multiRoot'` for sticky root routing, plus Host Settings exposure for authenticated connections.
- Made enterprise/local migration easier by adding a temporary managed Local harness permission (`vscode.temporaryAllowLocalHarness`) to block Local and force Copilot Agent Host.
- Private Marketplace extensions are now properly blocked at install time using gallery metadata enforcement, with clear origin-specific denial messages.
- Improved responsiveness for large Agent Host chats (move/open/reload) and fixed chat model picker selection so it no longer overwrites re-selections mid-pick.
