## Summary

- Chat Browse now renders partial results and progress incrementally as marketplace sources load, so it no longer stays blank while waiting for all sources.
- Agents/Chat: added “Conversation” persistent progress mode that collapses reasoning/tool calls into timed sections between response text (config: `chat.experimental.persistentProgressVerbosity=conversation`).
- Agents window: added Keep/Undo support for agent-host working set edits, and fixed composer/Send binding regressions in shared/new session composers.
- Quick Open: pasted web links now show available “open link” handlers (default browser + extension openers) with keyboard support (Alt+Enter/side button).
- Agents/Chat fixes: permission UI now explains disabled modes instead of hiding them; restored chat progress border glow; fixed cloud session title mismatches across editor/Agents windows.
- Agent Host: added macOS Computer Use permission setup modal (Accessibility + Screen Recording) so local Agent Host users can complete required checks in one place.
