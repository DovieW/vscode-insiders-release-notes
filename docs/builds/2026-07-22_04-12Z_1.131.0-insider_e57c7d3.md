## Summary

- chat: support inline attachment references so you can reference existing attachments in-chat without re-sending large payloads (#/ @), improving prompt context accuracy.
- chat: enable experimentation for `chat.defaultModel`, allowing its default to be overridden via the experimentation service for A/B rollouts.
- Agents: add sticky prompt header with up/down navigation buttons for stepping through prompts.
- Fixes Agent Host subagent streaming/resource handling so nested child tool results render under the correct parent.
- Voice/Dication: improve reliability and UX—use AudioWorklet mic capture, show filled mic when recording, and hide the editor caret during dictation.
- Fix chat/default model correctness: apply `chat.defaultModel` to every new Local chat session, preventing accidental carryover from the previous session.
