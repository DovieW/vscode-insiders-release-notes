- [#319737](https://github.com/microsoft/vscode/pull/319737) **Add telemetry for context and thinking effort changes**

  > Expands VS Code smoke tests with “hello world” coverage for chat session entry points (including CLI and Claude). Helps catch regressions earlier using the existing mock LLM setup.

  > Adds support for discovering “agent instruction” markdown files in Agent Host customizations and exposes them as rule children. Improves how agent instructions are surfaced to Copilot with special handling.

  > Updates breadcrumbs conditions so “Copy Breadcrumbs Path” is only enabled when symbol breadcrumbs are present. Matches the command’s existing no-op behavior and avoids misleading UI.
