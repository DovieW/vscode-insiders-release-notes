## 🐛 FIXES

- [#314978](https://github.com/microsoft/vscode/pull/314978) **Disable unsupported built-in extensions in sessions window**
  > Stops unsupported built-in extensions from loading in the Sessions window, while keeping the built-in chat extension working. Users get fewer broken/unsupported UI contributions there.
- [#314953](https://github.com/microsoft/vscode/pull/314953) **Ensures that component fixtures dont leak disposables**
  > Tightens component test fixture cleanup so created objects are properly disposed and don’t leak. This helps keep browser tests stable and reduces flaky behavior.
- [#314973](https://github.com/microsoft/vscode/pull/314973) **Fix gap between radio buttons in tabbed action list**
  > Reduces spacing between the radio buttons in the tabbed action list for better alignment. Improves the visual polish of the action widget.
- [#314936](https://github.com/microsoft/vscode/pull/314936) **fix: disable auto model feature in CLI configuration**
  > Disables the CLI “auto model” feature by default and updates test expectations accordingly. Users won’t get that behavior unless they explicitly enable it.
- [#306955](https://github.com/microsoft/vscode/pull/306955) **guarantee that return of TreeDataProvider.getChildren() is not mutated by vscode**
  > Guarantees VS Code will not mutate arrays returned by TreeDataProvider.getChildren (types and docs). Extension authors can safely treat child lists as immutable.
- [#314964](https://github.com/microsoft/vscode/pull/314964) **BYOK: Avoid auth token retrieval for diagnostics purposes only**
  > Avoids fetching an auth token when generating chat diagnostics by using cached copilotPlan when available. This reduces unnecessary auth work on error paths.
- [#314956](https://github.com/microsoft/vscode/pull/314956) **Enhance shimmer effect for in-progress session titles**
  > Improves the shimmer effect for in-progress session titles by enabling it only when supported and when reduced motion is not requested. Helps avoid rendering/accessibility issues.
- [#314795](https://github.com/microsoft/vscode/pull/314795) **Guard terminal resize/dispose race against xterm.js dimension getters**
  > Prevents terminal resize/dispose races that could crash in xterm.js by adding early bailouts and safer dimension access. Reduces “dimensions” errors when terminals are closing during resizes.
- [#314935](https://github.com/microsoft/vscode/pull/314935) **Disable unified quick access when AI features are disabled**
  > Stops routing “Quick Open with Modes” into Unified Quick Access when AI features are disabled. Users won’t see AI/chat-related entries in Quick Input under that setting.
