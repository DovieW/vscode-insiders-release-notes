## Summary

- Add a persisted, toggleable “VS Code pet” to chat/agent composers (with reduced-motion + accessibility guidance).
- Experimental dictation transcript cleanup: incrementally refine while speaking and optionally run final text through an LLM (with safe raw fallback).
- Uninstall local plugins: adds an “Uninstall” action that removes removable local plugins from configured locations without deleting the actual files.
- Voice/chat workflow updates: segmented voice/dictation toggle (hold-to-talk/listen styles) plus a fix so live voice doesn’t cut off early.
- Fixes for Agents/Agent Host stability: prevent chat shell output lifecycle leaks, reuse terminals when replacing session drafts, and stream partial tool output live to the terminal channel.
