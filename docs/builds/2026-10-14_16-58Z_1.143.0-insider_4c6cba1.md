## Summary

- Improve Multi-Diff commit view: show rich metadata (add/delete counts, clearer subjects) and safely resolve path-hinted commits when opening from the list.
- Agents window updates: related chats now render as independent framed panels in multi-session layouts for better spacing/separators (including macOS corner rounding).
- Fix nested chat “Mark All as Read” to complete immediately by applying nested read updates in a single transaction, improving perceived responsiveness.
- Enterprise policy fix: Claude/Codex Agent Host chats that are policy-disabled are migrated/archived into “Continue in Copilot” (preserves transcripts, stops new sends).
- Timeline fixes: correct hover positioning in horizontal scrolling mode and more reliable Timeline command handling (avoids bad directory pinning).
- Fix several UI reliability issues: stop Explorer startup flashing when local history is disabled, keep Agents canvases/add-tab commands working across refreshes, and prevent search crashes from symlink loops.
