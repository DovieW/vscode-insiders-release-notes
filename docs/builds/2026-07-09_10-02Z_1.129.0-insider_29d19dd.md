## Summary

- sessions: expose session-management tools to Agent Host sessions—agents can list/create/delete sessions/chats and users get a deterministic “Open Session” link to jump to new items.
- Voice: buffer responses for unfocused sessions and add a pending speaker indicator + cue when audio is received, reducing confusion when switching between sessions.
- Voice: improve hands-free interaction with barge-in over the assistant (stop playback on speech) and add Escape to disconnect voice mode.
- Fix Copilot Next Edit Suggestions leaking into languages disabled by `github.copilot.enable` (NES now respects per-language enablement).
- chat: turn previews render as resource labels (and include markdown created/edited outside the workspace); previews are limited to markdown.
- Fix agent-host UI/terminal issues: hide shell IDs in Agent Host terminal output and show materialization failures as terminal session status instead of “Creating” stuck states.
