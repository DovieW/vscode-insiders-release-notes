## Summary

- Sessions: chat timeline variant for Agents—dock-style rail with one-dot-per-prompt and sticky navigation that jumps to the active prompt.
- Built-in on-device dictation now works in the editor and terminal (with extension fallback when unavailable), including transcription without needing the speech extension.
- Migrate Prompts: added a trash-aware delete action per prompt file with confirmation and immediate UI removal.
- Voice Mode &amp; Agents mic UX improvements: dictation-specific mic context menu, mutually hiding mic buttons, and Voice Mode defaults to hands-free.
- Fixes: honor Explorer minItems in Windows taskbar jump lists and prevent Agents window hang when editor limit per group is 1.

## ✨ NEW

- [#327007](https://github.com/microsoft/vscode/pull/327007) **Dictation/voice mic UX: context menu, mutual hide, spacing, hands-free default**
  > Improves Agents window mic UX by adding a dictation-specific context menu, making dictation/Voice Mode mic buttons mutually hide, and defaulting Voice Mode hands-free to on.
- [#326982](https://github.com/microsoft/vscode/pull/326982) **Extend built-in on-device dictation to editor and terminal**
  > Extends built-in on-device dictation to the editor and terminal, with extension fallback when built-in isn’t available. Adds terminal/editor transcription support without requiring the speech extension.

## 🐛 FIXES

- [#318117](https://github.com/microsoft/vscode/pull/318117) **Honor Explorer's \`minItems\` for the Windows taskbar jump list**
  > Fixes the Windows taskbar jump list “Recent Folders &amp;amp; Workspaces” section to honor the slot count Explorer/Electron requests, instead of a hardcoded 7 entries.
- [#327075](https://github.com/microsoft/vscode/pull/327075) **chat: Add Agent Host turn failure diagnostics**

- [#327047](https://github.com/microsoft/vscode/pull/327047) **fix: memory leak in debugModel**
  > Fixes a memory leak in debugModel by disposing inactive child debug sessions (and related objects) when their root session is replaced.
- [#327074](https://github.com/microsoft/vscode/pull/327074) **sessions: fix Agents window hang with per-group editor limit of 1**
  > Fixes a renderer hang in the Agents window by disabling editor-limit eviction and enforcing the correct tab layout for the single-pane editor part.
- [#327027](https://github.com/microsoft/vscode/pull/327027) **Fix Agent Host MCP output channels**
  > Fixes Agent Host MCP output so diagnostics go to the correct per-server Output channel and the customization editor is closed at the right time before revealing MCP output.
- [#327042](https://github.com/microsoft/vscode/pull/327042) **Voice Mode: replace settings gear with 'Configure' context-menu action**
  > Moves Voice Mode “Configure keybinding” and “Open settings” from gear buttons into the mic icon’s right-click context menu in both the normal and Agents windows.
- [#327030](https://github.com/microsoft/vscode/pull/327030) **sessions: open single-file diff directly from single-pane Changes view**
  > Fixes single-pane Changes view so clicking a file opens the single-file diff (or multi-file diff based on the existing setting/Alt behavior) instead of always forcing the aggregate diff.
- [#327025](https://github.com/microsoft/vscode/pull/327025) **Fix Voice Mode panel dictation misrouting to background chat editor**

- [#327015](https://github.com/microsoft/vscode/pull/327015) **Include typed chat input in voice mode requests**

- [#327011](https://github.com/microsoft/vscode/pull/327011) **Fix: apply chat.defaultModel on every new local session**
  > Fixes local agent sessions so `chat.defaultModel` correctly overwrites spillover models for new/empty sessions instead of incorrectly reusing the previous session’s model.
- [#327017](https://github.com/microsoft/vscode/pull/327017) **added classification comments for response events**

- [#326930](https://github.com/microsoft/vscode/pull/326930) **fix: memory leak in terminalProcessManager**
