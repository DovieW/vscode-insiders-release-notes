## Summary

- Add editable Markdown diff editing to the Agents window, including breadcrumbs/editor switching and quick-diff gutter markers.
- Browser: element commenting in the integrated browser so page annotations can be tied to chat attachments (new comment-mode UI, numbered pins, previews).
- Voice Mode onboarding: localized voice previews per language (de/es/fr/it/ja/ko/pt/zh) with a single native preview where supported.
- Fix: agent feedback submissions in sessions—wait for the chat model to load and mark feedback submitted when queued to prevent lost/stuck feedback.
- Fixes sessions/Agents window reliability: multi-root checkpoint support and prevent losing session pins/groups due to startup race or failed session listing.
- Fix chat UX issues: preserve symbol references while editing input and eliminate duplicate tooltips on the chat turn preview pill.
