## Summary

- Add “Developer: Restart Local Agent Host” to editor/Agents windows to restart and reconnect without losing your active chat.
- Enables Agent Host harness on remote servers (Codespaces, Remote-SSH, Dev Containers, WSL) by provisioning/wiring it on the remote side.
- Omni Chat: multi-session routing with a toggleable always-on-top input window and Voice Mode routed to the correct destination session(s).

- Performance/stability: caches generated built-in agent files idempotently and avoids oversized restricted telemetry requests that could trigger HTTP 413s.
