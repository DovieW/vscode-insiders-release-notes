## Summary

- Chat: sticky scroll in chat—pin a request header to the top while scrolling responses, toggle back to editing with another click; restore/fork actions keep working.
- Insiders: enable chat input pill features by default (session metadata above the input), while keeping both pill behaviors user-toggleable.
- Cloud Sessions: add a Sandbox checkbox when creating sessions (behind existing cloudSandbox setting) so you can choose sandbox vs regular provisioning.
- Chat/Agent Host: scope the 5s request timeout to only local-tool calls, preventing other-client requests (input/auth/confirmation) from being cancelled/denied.
- Agent Host: fix legacy Copilot CLI session migration on open (not just from the list) and prevent sessions getting stuck during provider discovery.
- Perf: improve chat debug-log export by streaming local logs directly into the ZIP (avoids IPC transfers of renderer strings).
