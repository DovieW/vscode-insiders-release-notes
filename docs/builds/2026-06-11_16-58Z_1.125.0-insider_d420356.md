## 🐛 FIXES

- [#320958](https://github.com/microsoft/vscode/pull/320958) **CopilotAH: fix watcher regression**
  > Fixes a watcher regression so session customization discovery refreshes when files under non-recursive watched folders (like .github/agents) change. Adds targeted tests to prevent repeats.
- [#320897](https://github.com/microsoft/vscode/pull/320897) **Propagate Copilot usage from SDK to agent session**
  > Propagates Copilot usage/credit metadata from the SDK into agent-host session usage so the UI shows accurate per-turn costs. Includes test coverage for cumulative usage.
- [#320825](https://github.com/microsoft/vscode/pull/320825) **A11y: Expose inline tree item actions to screen readers**
  > Improves screen reader accessibility for inline tree item actions by announcing when actions exist and labeling the toolbar as belonging to the focused tree item.
- [#320967](https://github.com/microsoft/vscode/pull/320967) **Improve markdown paste of nested html tags**
  > Fixes markdown paste when clipboard HTML contains code with HTML tag names, so inline code and fenced code blocks don’t lose those tag names. Adds regression tests.
- [#320956](https://github.com/microsoft/vscode/pull/320956) **Try fix flaky test**
  > Makes agent-host tests more reliable by waiting for pending root-config persistence to finish before cleanup. Adds a whenIdle hook on the configuration service and uses it in tests.
- [#320959](https://github.com/microsoft/vscode/pull/320959) **Adjust CIStatusWidget header height and update CSS margins for improved layout**
  > Adjusts CIStatusWidget header height and CSS margins for better layout alignment, including when sections are collapsed. Updates the shared header height constant used by sizing logic.
- [#320950](https://github.com/microsoft/vscode/pull/320950) **Try to make the Chat Sessions smoke tests more reliable by closing the chat editors at the end**
  > Improves reliability of Chat Sessions smoke tests by closing any open chat editors during test teardown. This reduces focus-related flakiness between test runs.
- [#319736](https://github.com/microsoft/vscode/pull/319736) **Improve split editor menu items for agents window and compact window editor**
  > Improves editor action placement in the Agents (sessions) window by moving Split Editor and multi-diff collapse/expand actions into the overflow menu. Keeps behavior the same in other contexts.
- [#320927](https://github.com/microsoft/vscode/pull/320927) **Fix CachedPromise to reset state on cancellation of in-flight computations**
  > Fixes a cancellation edge case in CachedPromise so a newly started computation doesn’t reuse a cancelled in-flight result. Prevents immediate-cancel behavior for new callers.
