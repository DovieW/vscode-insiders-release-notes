## Summary

- Add “Mark All as Read” to the Automations sidebar context menu to quickly clear eligible unread run history without opening the view.
- Agents window: add optional Session Toolbar beside the active chat (quick tabs like Changes/Files/Browser/Canvas, keyboard &amp; drag support).
- Model picker: add arrow-key navigation for expand/collapse and provider picker icons, improving accessibility and keyboard-only workflows.
- Markdown: support pasting video/audio from native clipboard/context menu while preserving filename/type; fixes a webview focus race in the native paste flow.
- Fix chat rendering/answer preservation across tool/folding chains, plus GitHub environment sharing for multiple signed-in accounts.
