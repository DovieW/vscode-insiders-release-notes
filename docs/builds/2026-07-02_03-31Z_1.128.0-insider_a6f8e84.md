## Summary

- Enable “cache-break” hint in the chat model/options picker by default (removes the experimental gate), while still hiding it when dismissed, cache-warm, or suppressed by the model.
- Agents window now supports workspace-less “Quick Chats” via a dedicated Chats section, with per-session scratch storage and agent-host run/restore behavior.
- Add read-only chat support in the Agents window: subagent (worker) chats appear as locked, read-only tabs with a read-only banner and “Open Subagent”.
- Fix Agents window multi-session tools: remove Tasks tools and the Problems tool from the sessions context so Problems only appears in the intended non-sessions tasks set.
- Improve Agent Host reliability: attach opened/unsaved docs for agent sessions, fix per-chat working directory projection, and correct terminal decoration exit codes using SDK shell_exit metadata.
