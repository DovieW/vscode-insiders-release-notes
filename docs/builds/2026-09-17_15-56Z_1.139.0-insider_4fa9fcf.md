## Summary

- Added `sessions.applicationBadge` to control which session types contribute to the app badge (defaults to input-needed; unread and CI-failing are opt-in).
- Fixes stale screen-reader announcements of the chat agent count after workspace-agent deletion/customization by updating the ARIA status correctly.
- Fixes same-document fragment links in the custom Markdown editor so TOC/anchor navigation jumps to the correct target.
- Prevents crash-orphaned provisional chat sessions from becoming impossible to reopen and improves the retry error message when providers are still starting.
- Recognizes crash-orphaned provisional sessions and other session-edge cases: inline session rename fixes virtualized row visibility, wrapper resolution, and draft preservation.
- Fixes snap packaging by removing the XDG_DATA_HOME override that broke terminal history, trash, and font configuration.

## ✨ NEW

- [#336565](https://github.com/microsoft/vscode/pull/336565) **sessions: make mark-as-done confetti setting experiment-configurable**
  > Made the Sessions “mark as done” confetti setting’s effective behavior experiment-configurable. This enables A/B testing without changing the default or non-enrolled behavior.
- [#336543](https://github.com/microsoft/vscode/pull/336543) **sessions: Customize application badge session categories**
  > Added the `sessions.applicationBadge` setting to control which session types contribute to the application badge. Defaults to input-needed sessions, with unread and CI-failing sessions opt-in.

## 🐛 FIXES

- [#336282](https://github.com/microsoft/vscode/pull/336282) **Stale Chat agent accessibility count after workspace-agent deletion**
  > Fixes stale screen-reader announcements of the agent count after an agent is deleted/customized. Ensures the ARIA status updates so users hear the correct number.
- [#336566](https://github.com/microsoft/vscode/pull/336566) **Fix same-document links in Markdown editor**
  > Fixes same-document fragment links in the custom Markdown editor so TOC/anchor navigation reveals the correct target. Keeps existing behavior for external/cross-document links and previews.
- [#336480](https://github.com/microsoft/vscode/pull/336480) **agentHost: recognise a crash-orphaned provisional session**
  > Fixes a crash orphaning a provisional chat session so it becomes impossible to open afterward. Also updates the error message to tell users to retry shortly if a provider is still starting.
- [#336553](https://github.com/microsoft/vscode/pull/336553) **sessions: fix inline rename edge cases**
  > Fixes edge cases in inline session rename, including virtualized row visibility, chat wrapper resolution, and preserving rename drafts. Improves validation UI/layout during renderer recycling.
- [#292808](https://github.com/microsoft/vscode/pull/292808) **fix: do no configure XDG\_DATA\_HOME for snap**
  > Fixes the snap package by removing the XDG_DATA_HOME override that broke terminal history, trash, and font configuration. Ensures snap doesn’t redirect unrelated XDG_DATA_HOME userspace paths.
- [#336542](https://github.com/microsoft/vscode/pull/336542) **Remove obsolete prompt files**
  > Removes obsolete prompt configuration files (`implement.prompt.md` and `no-any.prompt.md`). No user-facing behavior change expected; validation was skipped since it’s just deletions.
- [#336487](https://github.com/microsoft/vscode/pull/336487) **sessions: show pending automatic host connections on web**
  > Keeps the web `/agents` connection indicator showing **Connecting** while automatic setup is still pending, and improves diagnostics timing/state capture and focus behavior when reports open on phones.
