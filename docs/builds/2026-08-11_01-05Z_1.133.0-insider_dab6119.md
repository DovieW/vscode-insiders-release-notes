## Summary

- Agent Host: start client tools as soon as parameters are ready, using local confirmation to prevent duplicate runs and reporting confirmation state back to the Agent Host protocol.
- Sessions view: add a final workspace preselection fallback when recent history can’t pick a workspace, and record the preselection source in first-time telemetry.
- Agent Host fix: avoid deprecated URL parsing in WebSocket token handling to prevent Node DEP0169 warnings and validate decoded token connection more reliably.
- Agents performance: speed up “list sessions” by skipping Git worktree root repairs during listing (defer until session open/restore).
- Auto discounts: remove the synthetic “fake discount” probe and derive discount ranges from existing model billing metadata instead.
- Improve V3 onboarding: extend GitHub prompt resolution timeout, add a Close action, and support GitHub Enterprise endpoints/auth/API with privacy-safe telemetry + better contrast.

## ✨ NEW

- [#330131](https://github.com/microsoft/vscode/pull/330131) **agentHost: use local confirmation for client tools**
  > Updates Agent Host client tools to run as soon as parameters are ready, using local confirmation to decide whether to proceed. Confirmation state is reported back to the Agent Host protocol to prevent duplicate runs.
- [#329912](https://github.com/microsoft/vscode/pull/329912) **[cherry-pick] Add session workspace preselection fallback**
  > Adds a final workspace preselection fallback for the new Sessions view when recent history can’t pick a workspace. It also records where the preselection came from in existing first-time telemetry.

## 🐛 FIXES

- [#330118](https://github.com/microsoft/vscode/pull/330118) **[cherry-pick] Remove fake prompt discount probe**
  > Removes the synthetic “fake discount” probe and instead derives Auto discount ranges from existing model billing metadata. This avoids extra probing while keeping discount behavior consistent.
- [#330084](https://github.com/microsoft/vscode/pull/330084) **[cherry-pick] agentHost: avoid deprecated URL parsing**
  > Replaces deprecated URL parsing in Agent Host WebSocket token handling to avoid Node DEP0169 warnings that could fail sanity tests. Adds targeted coverage for decoded token connection validation.
- [#330017](https://github.com/microsoft/vscode/pull/330017) **[cherry-pick] agentHost: perf: stop repairing worktree roots while listing**
  > Speeds up the Agents “list sessions” path by removing Git worktree root repairs during listing, using persisted metadata instead. Repair is deferred to session open/restore, and new tests cover both cases.

## 🔨 REFACTORS

- [#329931](https://github.com/microsoft/vscode/pull/329931) **[cherry-pick] Agents window: Update badge positioning and refactor activity bar styling for sessions**
  > Refactors Sessions panel and auxiliary tab-strip styling to use the shared Modern UI `tabs.css` rules for badge/icon layout. Updates browser tests and removes redundant per-panel CSS.

## 🛠️ DEVELOPER UPDATES

- [#329967](https://github.com/microsoft/vscode/pull/329967) **[cherry-pick] Fix watching problem collector replay growth**
  > Fixes an issue where replaying watching diagnostics after model close could grow the retained output buffer exponentially. Adds a regression test to ensure replay processing doesn’t duplicate lines.
- [#329924](https://github.com/microsoft/vscode/pull/329924) **Improve V3 onboarding prompt options**
  > Improves the V3 onboarding GitHub prompt options with longer resolution timeout, a Close action, privacy-safe telemetry, and support for GitHub Enterprise remotes/auth/API endpoints. Also boosts contrast across themes.
