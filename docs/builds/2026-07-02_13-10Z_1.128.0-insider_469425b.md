## Summary

- Make Agents onboarding tours experiment-ready by wiring experiment flags to “New Session” tours; onboarding tours and hints are now enabled by default in Workbench onboarding settings.
- Agents Sessions: Pinned section now always shows with an icon and “No pinned sessions” placeholder when empty for consistent UI.
- Agents chat sessions revamped: subagent chats hidden by default, closed chats persist across restarts, plus “Close All Chats” and improved chat capabilities.
- Chat Customizations → Tools: filter gallery results to only show extensions that actually provide runnable LLM tools (including in Agents/Sessions).
- AgentHost fix: resyncs default chat working directory/state/summaries after a session is materialized to avoid stale chat context.
