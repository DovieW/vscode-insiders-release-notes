## Summary

- Voice Mode &amp; Dictation now support customization via `voice.md`/`dictation.md`, plus new commands and backend instruction on session start/resume.
- Agents session UI improvements: worktree sessions show as pending until ready; side panel defaults to Files until changes; add comments in new session view.
- Chat UX: turn status pills are enabled by default, plus updated pill hover/ARIA text; dictation mic UI polished and adds `dictation.showTranscript`.
- Copilot/Agents reliability: support multiple working directories (opt-in) and fix agent-host attachment uploads; prevent duplicate repo watcher when Agent Host is enabled.
- Automations: allow agents to run automations on demand via `runAutomation`; fixes multiple automation UI/layout issues (overflow, max-width).
