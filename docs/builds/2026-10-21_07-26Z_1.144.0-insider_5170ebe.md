# 2026-10-21 - 07:26Z

## Summary

- Agents: Move Chats now supports moving workspace-less sessions/chats (including between workspace-less and foldered). Adds validation and preserves folder info correctly during moves.
- Mission Control automations: add GitHub issue/PR event triggers, letting users create automations from GitHub events instead of only schedules.
- Chat: reserve cloud sandboxes ahead of time while composing (experiment). Includes safer fallback/cleanup and added diagnostics/telemetry to improve send latency.
- Agent Host: managed plugin preparation failure warnings now include a Retry action, so you can re-attempt plugin setup without waiting for the timeout.
- Copilot Chat: remove prompt override settings and restrict omitBaseAgentInstructions to user scope to prevent workspace values changing agent prompts.
- Fix Fusion/HydraFusion migration and picker behavior by dropping the routed “High” path; also simplify Fusion switches to only use dynamic auto tiers.

## ✨ NEW

- [#343022](https://github.com/microsoft/vscode/pull/343022) **Agents: move workspace-less sessions and chats in Move Chats (Block 9)**
  > Agents “Move Chats” now supports moving workspace-less sessions and moving chats between workspace-less and foldered sessions. It adds validation rules and preserves/records folder info correctly during moves.
- [#343091](https://github.com/microsoft/vscode/pull/343091) **sessions: Add issue and pull request automation triggers**
  > Adds issue and pull request event triggers to the Mission Control automation dialog. Users can now author automations based on GitHub events, not just schedules.
- [#343123](https://github.com/microsoft/vscode/pull/343123) **Rename Fusion to Copilot Fusion and apply its finalized picker strings**
  > Renames “Fusion” to “Copilot Fusion” across the model picker, including tiers, hovers, footer text, discounts, and accessibility help. Updates UI strings and wiring for the finalized picker copy.
- [#342923](https://github.com/microsoft/vscode/pull/342923) **chat: prepare cloud sandboxes while composing**
  > Prepares cloud chat sandboxes ahead of time while composing (behind an experiment setting) by reserving work before Send. Includes safer fallback/cleanup logic plus new diagnostics and telemetry.
- [#343121](https://github.com/microsoft/vscode/pull/343121) **agentHost: add Retry to managed plugin failure warning**
  > Adds a “Retry” action to the managed plugin preparation failure warning in Agent Host chat. Users can re-attempt plugin setup without waiting for the automatic retry timeout.

## 🐛 FIXES

- [#343147](https://github.com/microsoft/vscode/pull/343147) **Drop Fusion's routed High path and the tests for it**
  > Fixes HydraFusion-to-Fusion model migration by simplifying the model picker to the only supported Fusion “High” routing shape. This prevents chats from moving at the wrong time and updates related tests/accessibility...
- [#343128](https://github.com/microsoft/vscode/pull/343128) **Remove the Copilot Chat prompt override settings**
  > Removes Copilot Chat debug prompt override settings and restricts omitBaseAgentInstructions to user scope. This prevents workspace values from incorrectly changing agent prompt behavior.
- [#343126](https://github.com/microsoft/vscode/pull/343126) **Remove the run\_vscode\_command agent tool**
  > Removes the Local-harness agent tool `run_vscode_command` (and its dependent local skills). The user-facing agent behavior changes so the tool no longer appears and prompts don’t reference it.
- [#343120](https://github.com/microsoft/vscode/pull/343120) **Remove the install\_extension agent tool and install-vscode-extension skill**
  > Removes the Local-harness `install_extension` agent tool and the `install-vscode-extension` skill. The agent now recommends extensions via `.vscode/extensions.json` instead of installing them directly.
- [#342970](https://github.com/microsoft/vscode/pull/342970) **Engineering - tell operators how to finish publishing after a stage retry**
  > Improves Publish failure output in build runs so operators get clear instructions for finishing publishing after retrying only a failed platform stage. Keeps failure behavior the same, but makes recovery actionable.
- [#342982](https://github.com/microsoft/vscode/pull/342982) **agentHost: wait for on-disk test databases to close before deleting their directory (Windows EBUSY)**
  > Fixes Windows EBUSY teardown flakes in agent-host database compatibility fixtures by waiting for databases to fully close before deleting their temp directories. This is test-only and prevents CI race failures.
- [#343107](https://github.com/microsoft/vscode/pull/343107) **Make dynamic Auto tiers the only switch for Fusion**
  > Makes `chat.copilot.dynamicAutoTiers.enabled` the only switch that controls how “Fusion” models appear, removing old Fusion toggles and inline tier rows. Updates fallback behavior and telemetry accordingly.
