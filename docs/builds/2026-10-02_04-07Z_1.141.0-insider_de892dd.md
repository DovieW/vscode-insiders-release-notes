# 2026-10-02 - 04:07Z

Commit: [de892dd](https://github.com/microsoft/vscode/commit/de892dd1f9971e3a7d8c758a8788d86854047605) · Previous: [ec2e580](https://github.com/microsoft/vscode/commit/ec2e580674cdb512aa9b2a9596ab35d8a9590f1e) · Compare: [GitHub](https://github.com/microsoft/vscode/compare/ec2e580674cdb512aa9b2a9596ab35d8a9590f1e...de892dd1f9971e3a7d8c758a8788d86854047605)

## Summary

- Enable local session-store support for Chronicle in Copilot Agent Host sessions (controlled by `github.copilot.chat.localIndex.enabled`), improving continuity for new and resumed sessions.
- chat: automatically trust cloud sandbox environments so Codespaces/sandbox operations don’t prompt inconsistently for workspace trust; sandbox trust is scoped and registered via a new API.
- sessions: show per-chat activity in the Sessions list, plus add side-by-side header close actions for sessions/chat groups to make finding and closing items faster.
- chat: prevent progress completion jumps/timestamp overlap and fix several chat UI lifecycle issues to stop visual glitches during tool/progress/composer updates.
- agentHost: cap BYOK tools at 128 and warn when tools are dropped so BYOK chats don’t fail when many tools are enabled.
- github: distinguish GraphQL throttling from true quota exhaustion to avoid incorrectly blocking all GraphQL until the quota window resets.
