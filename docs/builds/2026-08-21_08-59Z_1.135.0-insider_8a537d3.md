## Summary

- Add end-to-end trace logging when opening chat/agent sessions, showing where time is spent from session list to first chat widget render.
- Add setting-gated semantic workspace search to Copilot agent host sessions (routing, prompts), using VS Code’s built-in search implementation.
- inline chat: experimental Agent Host backend (off by default) for faster ephemeral sessions via disk-based review snapshots.
- Sessions/Agents UI: responsive “Agents Window Session Changes” diffs (side-by-side when possible, inline fallback) with persisted layout preference.
- Fix chat transcript Find: correct match reveal counts and newest-first navigation from the current viewport (debounced to avoid flicker).
- Agents Window sessions: dispose associated terminals when sessions are archived to prevent leaked terminals.
