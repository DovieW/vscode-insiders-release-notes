## Summary

- agentHost: allow Codex bootstrap before model discovery so Agents/Editor Chat UI no longer blocks Codex selection for signed-in users (e.g., Copilot Free).
- sessions: add experimental sessions.list.defaultSortOrder to control default Sessions list sorting by created or updated.
- Responses API: add explicit prompt caching breakpoint placement (incl. GPT-5.6/GPT-6 variants), enabled by default for supported models.
- Fix peer chat catalog migration race that could overwrite newly created peer chats with stale “missing” results.
- Fix Agents window account policy enforcement: hide Welcome/Try invitations when disabled and block direct --agents launches.

## ✨ NEW

- [#337029](https://github.com/microsoft/vscode/pull/337029) **agentHost: allow Codex bootstrap before model discovery**
  > Enables Codex selection/bootstrapping in Agents and Editor Chat before model discovery, including for signed-in users like Copilot Free. It fixes UI gating caused by “no visible models yet” logic.
- [#337027](https://github.com/microsoft/vscode/pull/337027) **sessions: Add configurable default session sort order**
  > Adds an experimental `sessions.list.defaultSortOrder` setting so the Sessions list can default to sorting by created or updated. Explicit user choices still override the default.
- [#336967](https://github.com/microsoft/vscode/pull/336967) **Add explicit Responses API prompt caching**
  > Adds explicit prompt caching breakpoint placement for the Responses API, including support for newer GPT-5.6/GPT-6 variants, with caching enabled by default for supported models.

- [#337048](https://github.com/microsoft/vscode/pull/337048) **[cherry-pick] test: remove external network dependency from browser tools**
  > Replaces an external website dependency in the browser tools integration test with a local loopback HTTP server to stop timeouts/flakiness, while keeping remote coverage.
- [#337032](https://github.com/microsoft/vscode/pull/337032) **[cherry-pick] sessions: revert Customizations sidebar reorganization**
  > Reverts a Customizations sidebar reorganization for this release, restoring the prior expandable layout and Sessions header/behavior. Aims to stabilize the UI regression from the previous change.
- [#336975](https://github.com/microsoft/vscode/pull/336975) **Fix peer chat catalog migration racing with chat creation**
  > Fixes a race where peer chat catalog migration could overwrite newly created peer chat data with stale “missing” results. Adds targeted regression coverage for the restart scenario.
- [#336979](https://github.com/microsoft/vscode/pull/336979) **agentHost: keep a provider readable after a partial catalog import**
  > Prevents agent-provider catalogs from becoming unreadable after a partial import by decoupling “provider answered” from “all candidates imported cleanly.” Keeps relevant sessions visible and retry semantics intact.
- [#336968](https://github.com/microsoft/vscode/pull/336968) **Fix account policy enforcement in the Agents window**
  > Fixes account policy enforcement for the Agents window: Welcome/“Try…” invitations are hidden when agents are disabled, and direct `--agents` launches are blocked so policy state is consistent.
