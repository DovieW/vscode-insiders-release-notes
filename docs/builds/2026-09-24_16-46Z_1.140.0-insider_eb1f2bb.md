## Summary

- Redesigned the customizations modal with a new tree/tabs layout, plus an experimental toggle for switching layouts for Plugins and MCP.
- Revamped the tabbed model picker card with icons and a faster “thinking level” entry point for clearer, quicker model configuration.
- Agents adds read-only multi-file diff editors for edit-tracked changesets, making it easier to review changes safely before editing.
- Sessions now has an “External” section with a capability-gated Import action to organize and import external sessions inline.
- Fixed multiple Agents/Sessions issues including preserving session identity on first send, scoping recorded PRs to the session folder, and preserving Dev Container mode for new sessions.
