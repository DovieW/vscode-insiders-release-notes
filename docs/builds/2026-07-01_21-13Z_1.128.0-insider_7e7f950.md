## Summary

- Allow Integrated Browser to open new tabs in a dedicated side group or auxiliary window (configurable), improving focus for browser content.
- System-wide keybindings: add `systemWide: true` in keybindings.json so shortcuts work globally even when VS Code isn’t focused.
- Agents window: “Open in VS Code” now opens the matching Chat session too; plus add “Discard Changes” into the multi-file diff per-file toolbar.
- Server-provided model warnings now show in the chat model picker hover, so users see reliability/usage warnings before selecting a model.
- Fixes: restore OS file explorer paste into VS Code Explorer; and fix BYOK utility background calls defaulting to Copilot utility models.
- Debugging UX: add a Copy button to the exception peek view to copy title, description, and stack trace to the clipboard.
