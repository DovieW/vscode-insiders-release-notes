## Summary

- Go to Symbol (⇧⌘O / Ctrl+Shift+O) now works in chat sessions, enabling Outline/Breadcrumbs navigation across chat exchanges.
- Copilot agent-host slash commands: update session permissions/mode without sending the command as a chat turn (works in Editor and Agents windows).
- Dictation improvements: show download progress ring instead of spinning mic, add a prompt to disable redundant VS Code Speech extension, and fix dictation shortcuts/state resets.
- Agents window: fix a Remote-SSH startup race, ensure all cloud sessions show regardless of active repo, and prevent hidden notebook tools from auto-enabling.
- Chat UI fixes: exclude agent-host completion entries from attachment pills, fix timeline rail scrollbar positioning, and resolve duplicate tool confirmation prompts.
